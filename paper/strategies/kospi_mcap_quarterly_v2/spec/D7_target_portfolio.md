# D7 목표 포트폴리오

- 상태: `DRAFT` (2026-09-17 16시대)
- 층: 판단 층 (판단 층 → 집행 층 계약의 출력)
- 게이트: G1 초안 / G2 코드 있음 / G3 합성 시험 통과 / G4 실행기에서 D6 산출을 받아 연결
- 코드: `src/targets.py` `cap_weights`, `build_target_portfolio`
- 블록: C6(20% 상한 반복 재배분), C7(정수화·10% 실패 기준)

## 입력
- D6 선정 50종목 (market_cap, close)
- D3 노출 (1.0 / 0.5)
- 설정: 전략 자본 ~~3,000만원~~ **6,000만원(09-17 사용자 승인, 아래 노출 50% 실패 대응)**, 상한 20%, 비용 준비금 0.5%

## 판정

**1. 상한 (C6)**
```
원시 비중 = 시총 / 50종목 시총 합
20% 넘는 종목은 20% 로 고정 -> 남은 비중을 나머지에 시총 비율로 재배분 -> 새로 넘으면 반복
합계 = 1 (오차 1e-10 이내), 최대 20% 이내
```
상한은 노출 곱하기 **전** 바스켓 기준이에요. 노출 50% 면 계좌 기준 종목 상한은 10%.

**2. 금액**
```
배분 가능 금액 = 전략 자본 × (1 − 비용 준비금 0.5%)
목표 예산     = 배분 가능 금액 × 노출
종목 목표금액 = 배분 가능 금액 × 바스켓 비중 × 노출
```
비용 준비금 0.5% 는 **Claude 제안값**: 매수 쪽 비용 실측(왕복 0.343~0.358% 중 매도세 0.2% 제외분의 절반 ≈ 0.08% + 반 스프레드 약 0.07%) ≈ 0.15% 의 약 3배.

**3. 정수화 (C7)**
```
내림 수량에서 시작
-> 1주 추가가 목표금액 오차를 줄이고, 예산과 종목 상한을 지키는 종목 중
   개선액 큰 순(같으면 시총 큰 순, 코드 오름차순) 으로 1주씩 추가
-> 더 추가할 종목이 없으면 끝
0주 종목을 지우거나 남은 종목 비중을 다시 맞추지 않아요
```
가격: **선정일 종가**(계획용). 집행 가격(매도호가1)은 E 층에서 다시 정해요 — 이 차이 처리는 E1 명세에서.

## 출력
`target_portfolio_<선정일>.csv` — 종목별 `raw_weight, basket_weight, account_target_weight, target_value, price, floor_qty, added_qty, target_qty, actual_value, actual_weight, value_error`

요약: 상한 반복 횟수, 상한 걸린 종목 수, 예산, 투입액, 정수화 현금·비율, 노출로 의도된 현금, 0주 종목 수·비중

## 경계
- 주문(목표 − 보유)을 만들지 않아요. E1 몫이에요
- 0주 종목 때문에 N 이나 비중을 자동으로 바꾸지 않아요

## 안전장치
| 상황 | 판정 |
|---|---|
| 종목 5개 미만 | 멈춤 `CAP_TOO_FEW_NAMES` (20% 로 100% 배분 불가) |
| 비중 합 ≠ 1 / 상한 초과 | 멈춤 `CAP_SUM_ERROR` / `CAP_EXCEEDED` |
| 가격 0 이하 | 멈춤 `PRICE_INVALID` |
| 0주 종목 목표비중 합 ≥ 10% | 멈춤 `FAIL_INTEGERIZATION` |
| 정수화 남은 현금 / 예산 ≥ 10% | 멈춤 `FAIL_INTEGERIZATION` |
| 투입액 > 예산 / 계좌 기준 종목 상한 초과 | 멈춤 |

## 시험이 잡은 결함 (2026-09-17)
- `floor(100000/10)` 이 부동소수 오차로 9,999 가 됨 → 한 주 덜 삼. `+1e-9` 로 수리, 회귀 시험 추가

## 실측 (2026-09-17 자료, 3,000만원, N=50)

**노출 100% — OK**
```
상한 반복 1회, 상한 걸린 종목 2 (삼성전자 원시 32.8% · SK하이닉스 28.4% -> 각 20%)
예산 29,850,000  투입 28,232,400  정수화 현금 1,617,600 (5.4%)
0주 7종목 (목표비중 7.2%): 삼성바이오로직스·삼성화재·효성중공업·HD현대일렉트릭·고려아연·두산·LIG디펜스앤에어로스페이스
최대 계좌 비중 19.46%
```

**노출 50% — FAIL_INTEGERIZATION** ← 설계 결함 후보, 사용자 결정 필요
```
예산 14,925,000  투입 10,947,550  정수화 현금 26.7%  0주 20종목 (11.0%)
같은 조건에서 N 을 줄이면:  N=40 STOP / N=30 STOP / N=25 OK (0.037, 0.089) / N=20 OK
```
