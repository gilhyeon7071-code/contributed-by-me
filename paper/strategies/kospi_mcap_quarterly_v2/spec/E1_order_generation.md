# E1 주문 생성

- 상태: `DRAFT` (2026-09-17 16시대)
- 층: 집행 층 (판단 층의 목표 포트폴리오를 받는 첫 칸)
- 게이트: G1 초안 / G2 코드 있음 / G3 합성 시험 통과 / G4~G8 미착수 (실제 호가·보유·현금과 연결은 E2~E4 뒤)
- 코드: `src/orders.py` `plan_orders`, 공유 정수화 `src/targets.py` `floor_qty`·`add_shares_c7`, 호가단위 `utils/krx_tick.py`
- 블록: C9 A·B·C, C7, `utils/krx_tick.py` (가져온 이유는 아래 "블록" 절)

## 입력

| 입력 | 누가 주나 |
|---|---|
| 목표 포트폴리오 (종목, 시총, 바스켓 비중, 계좌 목표 비중) | D7 |
| 노출 | D3 |
| 전략 순자산 (선정일 기준) | 첫 재구성은 전략 자본 6,000만원(09-17 개정). 이후는 E4 원장 |
| 전략 보유 {종목: 수량} | E4 원장 (첫 재구성은 비어 있음) |
| 매수 가능 현금 | E4 + 확인된 매도 체결 |
| 호가 {종목: 매도호가1, 매수호가1, 각 잔량, 호가 시각} | E3 쪽 호가 조회 |
| 지금 시각 | 실행 시 |

## 판정

**비중은 선정일에 고정, 수량은 집행 시점 호가로 다시 계산** (C4·C9)

```
1. 호가 검사: 없음 / 5초 넘게 낡음 / 가격·잔량 0 이하 -> 주문 불가 종목
2. 주문 불가 종목의 목표 비중 합 >= 10%  -> 전체 멈춤 FAIL_EXECUTION_COVERAGE (매도 전에)
                               < 10%  -> 그 종목만 건너뛰고 부족 비중 기록, 재배분 안 함
3. 목표 수량 = C7 정수화 (가격 = 매도호가1 을 호가단위로 올림, 예산 = 배분 가능 금액 × 노출)
4-SELL 단계: 목표에 없는 보유 -> 전량 매도 / 목표보다 많은 보유 -> 차이만큼 매도
             지정가 = 매수호가1 을 호가단위로 내림
4-BUY  단계 (매도 체결 확인 뒤): 목표보다 적은 종목 -> 차이만큼 매수
             지정가 = 매도호가1 을 호가단위로 올림
             필요 금액 × (1 + 매수 비용 추정 0.15%) > 매수 가능 현금 -> 멈춤 BUY_CASH_SHORT
             (수량을 조용히 줄이지 않는다 — C9)
5. 사전 차단: 같은 종목 매수·매도 동시 / 수량 0 이하 / 보유 초과 매도 / 주문 ID 중복 -> 멈춤
```

주문 방식은 사용자 결정 (가) 시장성 지정가(09-17). 호가 5초·커버리지 10%·다음 날 1회 재주문은 **C9 블록에서 가져온 것**이고 사용자가 따로 정한 값이 아니에요.

## 출력

주문 한 건:

```
strategy_id, rebalance_id(=전략ID|선정일), selection_date, execution_date,
target_version(목표 종목·비중 해시 12자리), intent_id(=rebalance_id|종목|방향|target_version),
attempt_no, order_id(=intent_id|attempt_no), code, side, order_type LIMIT, time_in_force DAY,
limit_price, requested_qty, notional, quote_ts, ask1, bid1, reason
```

요약: 주문 수·금액, 주문 불가 종목과 사유, 부족 비중, 건너뛴 매도, 예산, 매수 가능 현금

## 경계

- 주문을 **보내지 않아요**(E2 발주). 체결을 확인하지 않아요(E3)
- 원장을 고치지 않아요(E4)
- 호가를 직접 조회하지 않아요 — 받은 호가로만 계산

## 안전장치 (멈춤 코드)

`FAIL_EXECUTION_COVERAGE` / `BUY_CASH_SHORT` / `ORDER_QTY_NON_POSITIVE` / `SELL_EXCEEDS_HOLDING` / `BUY_SELL_SAME_CODE` / `DUPLICATE_ORDER_ID`
호가 없는 비목표 보유의 매도는 **추정 가격으로 내지 않고** 건너뛴 목록에 남겨요.
