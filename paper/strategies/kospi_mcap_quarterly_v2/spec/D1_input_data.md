## 판정

- 결합 키: 시세·지정 현황의 `종목코드` = 기본정보의 `단축코드`. **문자열 6자리 그대로**(영문 포함 코드 있음)
- 숫자: 종가·시가총액·상장주식수는 64비트 정수로 읽어요
- 교차 확인: `시가총액 == 종가 × 상장주식수` (확인된 사실상 오차 0). 다르면 그 종목 표시
- KOSPI200: 선정일 행이 있어야 하고, 선정일 포함 최근 200개 유효 종가가 있어야 해요
- 임계값 근거: 없음 — 이 칸은 판단을 안 해요

## 안전장치 — 아래면 **선정을 멈추고** 사유를 남겨요

| 상황 | 판정 |
|---|---|
| 세 파일 중 하나라도 없음 | 멈춤 `INPUT_FILE_MISSING` |
| 필수 열 없음 / 열 이름 바뀜 | 멈춤 `INPUT_SCHEMA_CHANGED` |
| 받은 날짜 ≠ 선정일, 또는 16시 이전에 받음 | 멈춤 `INPUT_NOT_SELECTION_DATE` |
| 행 수가 절대 범위 밖 | 멈춤 `INPUT_ROWCOUNT_OUT_OF_RANGE` |
| 행 수가 직전 선정일 대비 ±8% 넘게 변함 | 멈춤 `INPUT_ROWCOUNT_JUMP` |
| 시가총액 ≠ 종가×상장주식수 (상위 60) | 멈춤 `INPUT_MCAP_CHECK_IN_TOP60` — 순위는 파일 시가총액과 계산값 **둘 다**로 매겨 합친다(망가진 값이 스스로 순위에서 빠지는 구멍, 09-17 시험에서 발견·수리) |
| 파일 종류 판별 실패 / 같은 종류 2개 / 종류 누락 | 멈춤 `INPUT_FILE_UNKNOWN` / `INPUT_FILE_DUPLICATE_KIND` / `INPUT_FILE_MISSING` |
| 종가·시가총액이 0 이하 또는 숫자 아님 | 그 종목 표시, 시총 상위 60 안이면 멈춤 |
| 코드가 비었거나 6자리 아님 (정규화 **전** 원본 검사) | 멈춤 `INPUT_CODE_INVALID` |
| KOSPI200 선정일 행 없음 / 200개 미만 | 멈춤 `INDEX_NOT_READY` |
| 결합 안 되는 종목 | 목록 기록. 시총 상위 60 안이면 멈춤 |

"멈춤" 은 사고가 아니에요. **멈췄다는 사실이 기록되지 않는 것**이 사고예요.
