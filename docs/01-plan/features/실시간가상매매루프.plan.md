# Plan: 실시간 가상매매 루프

## 목표
장중(09:00~15:30) N분 주기로 KIS 모의투자 API와 연동하여
실시간 가격 기반 paper_engine을 자동 실행하는 완전한 루프 구축.

## 현황 분석
- `paper_engine.py` — EOD parquet 전용, 실시간 가격 주입 경로 없음
- `kis_realtime_ws.py` / `kis_order_dispatch_from_exec.py` — KIS mock API 구현 완료
- `p1_entry_policy.intraday.enabled = true` — 이미 활성화
- `entry_timing_mode = same_close` — 당일 종가 진입 모드
- 장중 반복 스케줄러 없음

## 구현 컴포넌트 (4개)

### 1. `tools/intraday_price_snapshot.py` (신규)
- KIS `inquire_price()` API로 후보 코드 현재가 조회
- `2_Logs/intraday_prices_latest.csv` 에 저장
- 컬럼: `ts, code, current_price, open, high, low`

### 2. `paper_engine.py` 수정 (최소 변경)
- `load_prices_for_codes()` 끝에 환경변수 `PAPER_INTRADAY_PRICE_PATH` 체크
- 파일 있으면 오늘 날짜 행을 실시간 가격으로 override (parquet 위에 merge)

### 3. `intraday_paper_loop.py` (신규)
- 장 시간(09:00~15:30) 동안 N분 주기 루프
- 각 사이클: 가격조회 → paper_engine → dispatch(mock) → sync_fills → stub업데이트

### 4. `run_intraday_paper.bat` (신규)
- KIS_MOCK=1 설정 후 intraday_paper_loop.py 실행
- 로그: `2_Logs/run_intraday_paper_last.txt`

## 실행 흐름
```
run_intraday_paper.bat
  └─ intraday_paper_loop.py  [09:00~15:30, 5분 주기]
       ├─ tools/intraday_price_snapshot.py  → intraday_prices_latest.csv
       ├─ paper_engine.py  (PAPER_INTRADAY_PRICE_PATH=intraday_prices_latest.csv)
       ├─ tools/kis_order_dispatch_from_exec.py --mock true
       ├─ tools/kis_sync_fills_from_api.py --mock true
       └─ vibe/buffett/vibe_make_live_fills_stub.py  (dashboard 갱신)
```

## 성공 기준
- 장중 5분마다 사이클 자동 실행
- 실시간 가격이 paper_engine에 반영됨
- KIS 모의투자 주문/체결 기록
- dashboard live_fills.csv 자동 갱신
