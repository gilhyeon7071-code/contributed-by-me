# Import Exports

Place local export files here before collection.

Supported folders:

- `slack_json`: Slack-style `.json` files.
- `meeting_text`: meeting `.txt` or `.md` transcripts.
- `doc_text`: document `.txt` or `.md` notes.

Run:

```powershell
E:\1_Data\run_llm_wiki_collect.bat
```

The collector writes contract Markdown into `00_Inbox\raw_*`.
