## 1. 목적 — 이것만 재고, 이것만 답한다

새 전략(`vol60` 상위 10% 배제, 광범위 동일가중, 2주 리밸런싱)의 **집행 비용**을 실측한다.

```
잰다        (1) 지정가 체결률과 체결까지 걸린 시간
            (2) 시장가 슬리피지 = (체결가 - 주문직전 중간가) / 중간가
            (3) 실제 수수료·세금, 그리고 왕복 총비용 vs 모델값 0.358%
안 잰다      수익성. 표본 6건으로는 검정력이 없다.
            수익성은 NSV_20260824_003 의 패널 측정이 답한다(83블록, 3.36년)
```

## 2. 왜 필요한가

왕복 **0.358%p** 는 수수료율·세율에서 산출한 값이고 **체결 실측이 아니다. 슬리피지가 빠져 있다.**
그런데 이 비용이 새 전략 순수익의 **31%** 를 차지한다 (연 1.83 / 5.9).
```
슬리피지가 왕복 0.3%p 만 더 들어도  ->  순수익 +3.85%p 가 절반이 된다
```
모집단 678종목 중 상당수가 거래대금 10~20억대 소형주다. 거기서 얼마가 드는지 **모른다.**
가상매매는 이 값을 만들어내지 못한다 — 체결을 가정하기 때문이다.

## 4. 대상 — 유동성 3구간 × 2종목, 종목당 예산 배분

**[개정 2026-08-24] 계좌 1 잔금이 40,256원이었고 사용자가 70,000원으로 증액한다.**
원안(1주씩 6종목 323,750원)은 불가능해 **저가주 + 종목당 예산 배분**으로 바꾼다.

주가 수준은 측정 대상(슬리피지)과 무관하다. 호가 단위 비율을 확인했다 —
611원 0.16% / 2,535원 0.20% / 20,200원 0.25% 로 **저가주가 특별히 불리하지 않다.**

모집단은 새 전략과 동일 (`value >= 1e9`, `vol60` 상위 10% 배제, 678종목).
예산 70,000원 중 12,000원을 예비로 남기고 종목당 9,666원.

2026-08-21 기준 시산 (**실행 당일 아침에 다시 뽑는다**):

```

유동성이 **23억~483억으로 21배** 벌어져 구간 비교가 성립한다.
선정 스크립트: `docs/research/new_signal/pick_measure_targets_budget.py`

**수량이 2~7주라 원안(1주)에서 못 보던 것이 추가로 관측된다 — 부분체결.**

**주의**: `950200` 은 9502xx 대역(외국기업/DR)이라 거래 특성이 다를 수 있다.
당일 재선정에서 국내 보통주로 대체 가능하면 대체한다.

**여전히 하한 측정이다.** 종목당 약 9,700원은 실제 운영 비중(1억을 733종목에
나누면 종목당 13.6만원)의 **1/14** 이다. 실제 슬리피지는 이보다 클 수 있다.

**자금 회전 주의**: 매도 대금은 T+2 결제다. 같은 자금으로 당일 재매수를 시도하지 않는다.
1일차 전량 매수 → 2일차 전량 매도로 끝낸다.

## 9. 위험

- **표본이 6건이다.** 슬리피지 추정의 정밀도가 낮다. 1회로 확정하지 말고
  구간별 차이의 **방향**만 읽는다. 정밀도가 필요하면 반복한다
- 1주 슬리피지는 실제 운영 규모의 **하한**이다. 과소평가 위험을 명시한다
- 하루 사이 시장이 크게 움직이면 왕복 손익이 비용 측정을 가린다.
  **손익이 아니라 체결가 대 기준가 차이만 본다**
- 소형주는 지정가가 하루 종일 안 채워질 수 있다. 그 경우 **미체결 자체가 결과다**

## 10. 성공 기준

  지정가 체결 여부 / 체결까지 시간 / 시장가 슬리피지(bp) / 실제 수수료·세금
이 기록되면 성공. 값이 크든 작든 성공이다.
실패는 "기록이 안 남는 것" 하나뿐이다.
```
