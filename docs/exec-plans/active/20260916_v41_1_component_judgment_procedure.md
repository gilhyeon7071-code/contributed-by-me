## 3. 원칙

1. **뼈대는 일반 절차, 살은 확인된 자료.** 이미 실측된 것은 다시 재지 않아요.
   단 결론 등록부 상태가 `재측정필요` / `범위한정` 이면 범위를 떼지 않고 그 상태대로 써요.
2. **예상값을 먼저 적어요.** 수정·측정 전에 문서 기준 예상값을 PLANS 에 적고, 실측과 다르면 그 차이를 발견으로 기록해요.
3. **한 번에 하나.** 부품 하나 변경 → 6축 → 기록 → 다음. 두 부품을 같이 바꾸면 효과를 귀속할 수 없어요.
4. **기준선 이동을 적어요.** 부품 하나를 바꾸면 다음 측정의 기준선이 바뀌어요.
5. **매매 행동을 바꾸는 변경은 방향을 숫자로 적어요.** 진입을 넓히나 좁히나, 노출을 늘리나 줄이나. "영향 없음" 금지.
6. **타임아웃은 원인이 아니에요.** rc=124 로 끝난 측정은 판정하지 않고 원인부터 봐요.
7. **v41.1 신호에 대한 2026-08-24 결론(진입 조건 11.6년 음수)은 유지.** 이 절차는 그걸 뒤집지 않아요.

### P6. 운용 검증

합격선(topn 에서 이관, 개정문):

```
A3  포지션 도달률      >= 90%
A4  발주 대비 체결률    >= 90%
A5  슬리피지 실측 중앙값 <= 0.50% (왕복)
```

**시작 전에 검정력을 계산해요 — topn 이 이걸 안 해서 40일을 기다려도 답이 안 나왔어요.**

```
체결률 p=0.90 를 ±5%p (95%) 로 추정  ->  n ≈ 1.96² × 0.9×0.1 / 0.05² ≈ 138 주문
"80% 이상" 만 확인                   ->  관측 90% 일 때 n ≈ 25 주문이면 단측 하한이 80% 를 넘어요
같은 날 주문은 독립이 아니에요       ->  거래일 수도 같이 적어요 (일 클러스터)
```

- 하루 주문 수 실측으로 기간을 역산하고, **기간을 사전등록**해요
- 수익률은 기록만. P6 판정에 쓰지 않아요 (그건 ② 수익률 단계의 일이에요)
- 표시·경보는 "확인 안 된 것부터". 조회 실패 뒤 원장 값을 실측처럼 띄우지 않아요

종료 조건: 사전등록 기간 도달 + A3·A4·A5 판정. 판정 불가 크기면 "판정 불가" 로 적고 연장 여부는 별도 결정
