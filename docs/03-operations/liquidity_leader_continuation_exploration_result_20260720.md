# 유동성 주도주 지속형 — 단일 가설 탐색 결과

## 고정 질문

20일 상대수익과 거래대금 가속이 높은 구조적 유동성 종목을 매일 최대 10개 선정했을 때, 다음 실제 거래일 시가 진입 후 비용 차감 h1/h2/h5 수익이 같은 날 적격 모집단보다 나은가?

## 고정 규칙

- KOSPI/KOSDAQ 보통주, 종가 1,000원 이상, 당일 거래대금 10억원 이상.
- 직전 20거래일 평균 거래대금 20억원 이상.
- 독립 계산 20일 수익률 및 당일 거래대금 가속이 같은 날 상위 20%.
- 종가가 MA20 위이고 MA20이 5거래일 전보다 높음.
- 위 조건 안에서 점수 상위 최대 10개를 선정.
- `PRICE_HISTORY_INTEGRITY_V1`, 다음 실제 전역 거래일 시가 진입, h1/h2/h5 실제 전역 거래일 종가 청산.
- 매수/매도 수수료 각 0.5%, 매수/매도 슬리피지 각 0.1%, 매도세 0.2%.

## 판정

이 **고정된 즉시 추세추종형**(상위 유동성 주도주를 다음 시가에 매수해 h1/h2/h5 보유)은 후보 생성 또는 운영 적용으로 지지되지 않는다.

이는 유동성 주도주라는 기회 유형 전체의 기각은 아니다. 이번 결과가 기각하는 대상은 지정된 신호, 당일 Top-10 선정, 다음 시가 진입, 짧은 고정 보유, 비용 계약의 한 결합이다. 진입 방식·보유 경로·청산 방식은 바꾸지 않았고, 이 결과를 보고 사후 조정하지 않는다.
