## 왜 닫는가 — 등록표 자신의 중단조건이 이미 충족돼 있었다

등록표에 이렇게 적혀 있다.
```
MDE       13.516 %p   (2026-08-31 쌍 이동블록 부트스트랩 실측 SE 4.824 x 2.8016)
MES        2.0  %p    (이보다 작으면 운용 전환 비용을 감수할 이유가 없다)
중단조건   MDE > MES 이면 시작하지 않는다
```
**13.516 > 2.0 이다.** 즉 이 라운드는 등록 시점에 이미 "시작하지 않는다" 조건을 만족했다.
닫는 것은 판단이 아니라 **등록된 규칙을 그대로 집행하는 것**이다.

풀어 쓰면: 이 설계로는 2.0%p 짜리 차이를 탐지할 수 없다. 탐지 가능한 최소 효과가
13.5%p 인데, 그 정도 차이가 실제로 있었다면 애초에 검정이 필요 없다.
n 을 늘려도 10.61년치가 이미 확보된 상태라 더 늘릴 자료가 없다.
