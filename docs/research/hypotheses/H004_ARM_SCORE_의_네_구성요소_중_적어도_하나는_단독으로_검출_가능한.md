## 2. 기계적 주장 (필수)

<!-- 부호까지 포함해 한 문장으로. 이 칸이 `rs` 사건을 막는 자리예요.

주장: 네 구성요소(`rs`, `v_accel`, `stretch`, `atr14_pct`) 중 **적어도 하나**가
      최선 십분위 기준으로 `MDE < |알파|` 를 만족한다
      부호: **예측하지 않아요.** 어느 방향이 좋은지도 미리 정하지 않고
      **십분위 10개를 전부 훑어 최선을 고릅니다**(사후 선택이므로 다중검정에 계상).
      `stretch`/`atr14_pct` 는 ARM 에서 빼는 항이라 낮은 십분위가 유리할 수 있어요
축의 정의: 생산 함수 `optimize_params_v41_1.compute_factors` 가 내는 값 그대로.
      재구현하지 않아요. 로더는 통합 패널(archive+Raw)
      ```
      rs         = ret20 - m_ret20            (차. 2026-07-28 에 비->차로 고침)
      v_accel    = value / 전일까지의 v_ma5
      stretch    = close / ma5
      atr14_pct  = atr14 / close
      ```
지평(h): h=13 (현재 하네스 값이자 H003 에서 **유일하게 판정이 열린 지평**).
      폭 N=50 (H003 에서 판정이 열린 폭). 유니버스 20억. 구간 2015-01-01~2024-12-31

## 3. 왜 그래야 하나 (기전)

산술이에요. 서로 다른 방향의 항을 동일가중으로 더하면 상쇄돼요.
`z(rs)+z(v_accel)` 은 "강하고 거래가 터진 종목", `-z(stretch)-z(atr14_pct)` 는
"덜 늘어나고 덜 출렁이는 종목" 을 원해요. **두 요구가 충돌하면 합은 아무것도 안 골라요.**

가중치가 전부 1인 것은 튜닝 금지 원칙의 결과지 최적성의 결과가 아니에요.
그 원칙 자체는 옳아요(과최적화 방지). 다만 **동일가중이 신호를 지운다면
그건 원칙의 문제가 아니라 축 선택의 문제**예요.

### **"중간이 최선" 은 정보가 아니에요** [중요]

알파가 유니버스 대비라 십분위 알파는 **제로섬**이에요. 실측한 10칸 합:
```
atr14_pct -0.25   rs +0.08   stretch -0.10   v_accel +0.02   (전부 0 근처)
```
**양 끝이 음수면 중간은 자동으로 양수**가 돼요. D1~D8 평균이 +0.04~+0.14 인 건
꼬리가 나쁜 것의 산술적 뒷면이지 신호가 아니에요.

양 끝을 뺀 D1~D8 안에서 보정선을 넘는 건 `v_accel D1`(t=3.25, **음수**) 하나뿐이에요.

### 판정 — 5번 반증조건 대조

- 기각1(네 축 전부 판정 불가) — **형식상 아니에요.** v_accel 2칸 / atr 5칸이 판정 가능이에요
- 기각2(판정되는 축의 최선 알파가 0.400%p 이하) — **경계.** 최선 +0.47%p 인데 보정 미달이에요

**형식으로는 기각1이 안 걸리지만 실질은 기각이에요.**
가설은 *"적어도 하나가 단독으로 검출 가능한 알파를 갖는다"* 였고,
검출된 건 **매수 알파가 아니라 회피 신호**예요.

### 측정 중 내가 틀려서 고친 것 [중요]

처음에 *"네 축 전부 중간이 최선인데 ARM 은 끝으로 민다 -> 설계가 반대다"* 라고 읽고
"네 항이 미는 십분위 알파 단순합 -0.40%p" 를 근거로 댔어요. **둘 다 철회해요.**

```
(1) "중간이 최선"  -> 제로섬의 산술적 결과. 정보 아님 (위 참조)
(2) "설계가 반대"  -> **정반대였어요.**
      보정을 넘는 유의한 결과는 atr D9(-1.66)와 v_accel D1(-0.50) 둘뿐인데
      ARM 은 -z(atr) 로 전자를, +z(v_accel) 로 후자를 **이미 올바르게 피해요**
      rs D9(-0.46) / stretch D0(-0.35) 는 유의하지 않아요
(3) "단순합 -0.40%p" -> 유의하지 않은 값들을 더한 수치. 인용 금지
```

### 남는 문장

> **10년, 거래 가능한 폭(N=50), 40칸을 다 훑어도 이 네 축에 매수 알파가 없어요.**

> **설계 오류가 아니라 정보의 부재예요. ARM 계열은 소진됐어요.**

H003(ARM_SCORE 합에 엣지 없음)과 H004(구성요소에도 없음)가 같은 방향을 가리켜요.
합이 0인 이유는 항이 상쇄돼서가 아니라 **항 자체가 0이기 때문**이에요.
