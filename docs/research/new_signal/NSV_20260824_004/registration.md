통합 패널 + 정제 후 전 구간 실측:

**위 수치는 열람된 구간의 값이므로 확증이 아니다.** 이 라운드가 확증한다.

## 아슬아슬한 점을 명시한다

```

```
**여유가 3% 미만이다.** 실제 효과가 추정보다 조금만 작아도 판정 기준 (2) 를 넘지 못한다.

`sd` 가 더 빨리 커져 필요 표본이 132~426블록(5.3~17.2년)으로 늘어난다 — 10% 가 가장 빠르다.
