## 왜 이 가설만 등록하는가

같은 스크린에서 저변동성 매수(D0)도 나왔으나 **등록하지 않는다.**
```
D0  h10 알파 +0.4834%p,  알파 sd 1.8954  ->  필요 블록 121  ->  4.9년
D9  h10 알파 -2.1028%p,  알파 sd 2.7382  ->  필요 블록  13  ->  0.5년
```
D0 는 효과가 작아 **판정에 5년 이상**이 걸린다. 시계를 돌려도 결론이 안 난다.

이 비대칭이 이 라운드가 남기는 부산물이다 —
**6개월~1년 안에 판정 가능한 매수 신호의 합격선은 h10 알파 1.5%p 이상**(82종목 바스켓 기준)이며,
지금까지 검토한 어떤 후보도 이 선을 넘지 못했다.
