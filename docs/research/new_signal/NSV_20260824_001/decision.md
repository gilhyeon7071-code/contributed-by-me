## 판정 근거

사전등록한 실패 기준: **"Train 주 지표가 MES(0.358%p) 미만이면 `NOT_SUPPORTED`"**

```
주 지표 +0.1414%p  <  MES 0.358%p     →  NOT_SUPPORTED
```

## 이것은 "효과가 없다"가 아니다

구분해서 기록한다.

```
효과의 존재    실재한다.  t=8.83,  95%CI 가 0 을 멀리 벗어남,  Train 5년 전부 양수
효과의 크기    부족하다.  +0.14%p 는 왕복 비용 0.358% 의 40% 수준
```

**회전해서 얻는 것(+0.14%p)이 회전해서 내는 것(0.358%)보다 작다.**
그러면 회전하지 않고 유니버스를 드는 편이 낫다. 그것이 MES 를 비용 1회분으로 정한 이유다.

`MDE 0.0449%p` 이므로 이 결과는 **표본 부족이 아니다.** 검정력 여유가 8배였고,
효과가 MES 만큼 있었다면 확실히 보였을 것이다. **진짜 음성이다.**

**그러나 이 관찰로 지금 가설을 바꾸지 않는다.** 기준서 §2 가 금지한 "결과를 본 뒤 조합을 바꾸기"에

그때도 §3.3 에 따라 전 구간 사용 시 `EXPLORATION` 상한이 걸린다.
