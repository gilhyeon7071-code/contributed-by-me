## 실패 기준을 왜 이렇게 잡았나 (2026-08-24, 관측 개시 전 정정)

첫 초안은 "**CI 하한 >= MES**" 였다. 그것은 MES 대비 **우월성 검정**이고,
`MDE <= MES` 가 보장하는 검정력(0 대비 검정)과 짝이 맞지 않는다.
실제로 판정 코드를 2020년 이후 162블록(요구의 2배)에 돌려 보니
점추정 +0.1514 (MES 초과) 인데도 CI 하한 +0.0917 < 0.14 로 `NOT_SUPPORTED` 가 나왔다.
통과하려면 관측 효과가 표본 추정치의 **1.7배**여야 한다 - 설계상 실패하는 검정이었다.

그래서 통상의 두 갈래 기준으로 바꾼다.
```
(1) 통계적 유의   CI 하한 > 0          <- MDE <= MES 가 이 검정력을 보장한다
(2) 실질적 유의   점추정 >= MES 0.14   <- 작아서 의미 없는 효과를 걸러낸다
```
같은 정정을 `collect.py` 에도 적용했다. **관측 개시 전이며 표본은 0 이다.**

한국 주식은 하루 ±30% 가 상한이므로 그를 넘는 1일 변동은 **정의상 수익률이 아니라
기업행위**다. 전수 조사 결과 `|r1|>30.5%` 가 1,548건(808종목), `|r1|>100%` 가
374건(331종목) 있었다. 빈도는 0.02% 지만 **극단값은 평균이 아니라 분산을 지배한다.**

실례: `000150` 이 2026-05-20 종가 7,140원 -> 05-21 종가 1,600,000원 (224배).
이 한 종목 때문에 2026-05-11 기간의 초과수익이 -18.56%p 가 되었고,
배제 20% 구간의 `t` 가 5.95 에서 1.89 로 무너졌다.

**(94) 에서 "winsorization 을 하지 않는 것이 정답" 이라고 결론냈는데 그것이 이 오염을
그대로 들여놓았다.** 옳은 처리는 보유기간 수익률을 자르는 것이 아니라
**가격제한을 넘는 1일 변동을 기업행위로 보고 그 h10 창을 제외**하는 것이다.
그것은 임의의 문턱이 아니라 제도적 사실이다.
