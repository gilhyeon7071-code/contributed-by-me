## 3. 우리가 틀린 것 — 이 조사로 드러난 우리 결함

### 3-1. 생존편향 측정 방식이 틀렸다  **[철회]**

2015~2019 창을 **제거**해서 1.35%p 라고 쟀다. 그건 생존편향과 레짐을 섞은 것이다.

```
올바른 방법   같은 창에서 상폐 종목을 넣고 다시 계산해 비교한다
한국 상폐 실측 검산   연 0.6 ~ 1.0%p 가 기대치
우리 값       유니버스 1.35%p (높은 쪽),  KOSDAQ 3.74%p (**산술로 설명 안 됨**)
```
KOSDAQ 3.74%p 에는 다른 것이 섞여 있다. 같은 창 재계산 전까지 귀속 금지.

### 3-2. "연 1회가 월 1회보다 총수익도 높다"  **[철회]**

```
총수익 격차 1.08%p (연1회 9.51 vs 월1회 8.43)
두 변형은 같은 종목을 대부분 들고 있어 **차이 계열**로 검정해야 한다
  추적오차 3%  -> t=0.88,  유의하려면 30년
  추적오차 5%  -> t=0.53,  82년
  추적오차 8%  -> t=0.33,  211년
```
**t ≈ 0.3~0.9. 노이즈다.** 비용 후 격차는 유효하나 총수익 격차는 근거 없다.
그리고 문헌은 오히려 반대쪽이다 — 느린 형성은 대개 총알파를 **깎는다**.

### 3-3. 상폐 수익률을 안 넣었다

상폐 종목을 **포함**했지만 마지막 거래일**까지만** 봤다. 그 뒤 0 이 되는 부분이 없다.

```

```
**우리 0.53% 도 여전히 낙관이다.**

### 3-4. 비용 상수가 시변인데 고정했다

```

## 4. 목표에 대한 판정 — 이게 제일 무겁다

### 백테스트가 실거래에서 얼마나 사라지나

```
[P] Suhonen 외 (2017) JPM   IB 판매 전략 215개   샤프 중앙값 **-73%**
[P] McLean·Pontiff (2016)   표본 외 -26%, 공표 후 -58%
[P] Huang 외 (2024) JFQA    스마트베타 ETF  백테스트 +2.77% -> 상장 후 -0.44%
```
**실거래 알파 ≈ 백테스트 알파 x 0.25 ~ 0.5**

### 목표별 필요치

```
목표 10%      필요 실거래 알파 +0.7%p   ->  백테스트에서 1.5 ~ 3%p 보여야
목표 20~25%   필요 실거래 알파 +11~16%p ->  백테스트에서 22 ~ 60%p 보여야
```
22~60%p 짜리 백테스트는 거의 항상 과적합의 증거라는 게 이 문헌 전체의 메시지다.

### **두 목표 다 판정이 안 된다. 이유가 서로 다르다**

```
10%      같은 창의 KOSPI200 이 22.50% 였다.  10% 는 패시브 대비 -12.5%p.
         어렵다는 게 아니라 **달성해도 "ETF 사서 가만히 있기" 대비 우위를 주장 못 한다**

20~25%   [P] Vanguard, 액티브 주식형 2,500개 25년
           장기 초과성과를 낸 펀드의 **80%가 5년짜리 하위 사분위 구간**을 겪었다
         -> **미달이 정상 경로**가 된다. 3년 미달 중단조건이 작동하지 않는다
```

### 20~25% 의 기저 확률

```
20%대를 10년 이상 유지한 사례   전 세계 한 자릿수 명
  버핏/버크셔  1965~2021 연 20.2% (지수 10.5%)   초과 +9.7%p 를 57년
  린치/마젤란  연 29.2% 이지만 **13년**에서 끝남
  메달리온     외부자금 안 받고 **용량을 의도적으로 묶은** 펀드
