# 컨텍스트 맵 — 누가 무엇을 소유하고, 경계에서 무엇을 주고받나 (2026-09-19)

- 용도: 여러 로직·도구가 **KIS 모의계좌 하나**를 같이 쓴다. 그 계좌의 소유 규칙이 도구 셋(원장 대조, 카나리아, 가부 기준)에 흩어져 있어서 한 장으로 모은다
- 근거: DDD(에반스·버논) — 바운디드 컨텍스트, 컨텍스트 매핑. 이 날 찾은 문제 넷이 전부 경계 위반이었다(PLANS 528·531·532·533·534)
- 성격: **구현을 바꾸지 않는다. 지금 구현이 무엇인지 적는다.** 규칙마다 근거 위치를 같이 적는다. 구현을 고치면 여기도 고친다
- 모의계좌는 ID 당 하나라 "각자의 길"(전략마다 계좌 분리)은 불가 → **공유하되 소유 규칙을 계약으로** 둔다
