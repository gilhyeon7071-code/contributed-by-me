# v41.1 진입 게이트 부품표

작성 2026-08-31 (PLANS (183)). 측정 스크립트 `scratchpad/gate_parts_audit.py`.
`generate_candidates_v41_1.py::_select_candidates()` 가 진입 후보를 정하는 전부다.
이 표는 그 안의 게이트를 하나씩 떼어 잰 것이다.

## 방법

```
패널      optimizer load_data + compute_factors, 2020-01 이후 3,950,873행 / 1,624 거래일
정제      가격제한 +-30.5% 기업행위 구간 제외 (전방 10일 내 발생분)
기준선    같은 날 유니버스 동일가중 fwd10
① 단독    그 게이트만 통과한 집합의 초과수익
② 한계    나머지 8개를 통과한 집합에서 (그 게이트 on) - (off). **부품이 값을 하는가는 이쪽이다**
보정      겹침 h=10 -> Newey-West(lag 10) HAC t. naive t 는 과대평가다
중단      한쪽 집합이 60일 미만이면 판정하지 않는다
```

**중요한 한계** - 이 측정은 **완화 사다리 L0**(원본 문턱)이다. 생산은 대부분의 날 L7 로
돈다([[gate_starvation_diagnosis]]). 따라서 이 표는 "설정된 게이트가 무엇을 하는가"이지
"오늘 실제로 산 종목이 무엇인가"가 아니다.

## 기준 - 게이트 9개를 전부 통과한 집합 (= 후보 집합)

```
신호일 563 / 1,624 (34.7%)      관측 817       하루 평균 1.45 종목
초과수익 -1.2829%p    naive t -1.82    **HAC t -2.02**
```
**조립된 기계는 같은 날 유니버스보다 유의하게 나쁘다.** 겹침 보정 후에도 그렇다.

즉 다른 게이트에 흡수돼 **사실상 아무것도 거르지 않는다.**

## 읽히는 것

```
1. 작동하는 게이트는 9개가 아니라 4개다 (2 v_accel / 4 value / 6 rsi14 / 8 high_52w_gap).
   나머지 5개는 비구속이고, 별도로 4개는 꺼져 있다
2. **손실의 주범은 value_min 1,550억 하나다.** 단독·한계 둘 다 -1.4%p 대, 유일하게 HAC |t|>2.
   빼면 후보 집합이 1.4%p 개선된다는 뜻이다
3. **유일하게 양의 한계 기여는 high_52w_gap 이다** (+2.389%p). 다만 HAC t 1.65 (p 약 0.10),
   150일 표본이라 확정이 아니다. 단독으로는 음수(-0.398%p)이므로 **상호작용이지 신호가 아니다**
4. 미측정이던 둘의 답: rsi14 는 값을 못 한다. high_52w_gap 은 3번
5. 시장 방어 게이트 4개가 전부 꺼져 있다. **시장 상태와 무관하게 매일 산다**
```

## 검정력 한계 - 과잉 해석 금지

한계 비교의 `on` 집합은 항상 후보 집합 그 자체(817 관측 / 하루 1.45종목)다.
따라서 **HAC |t|>2 를 넘은 것은 value 하나뿐**이고, 나머지 음수들은
"해롭다고 입증됐다"가 아니라 **"0과 구별되지 않는다"** 이다. 이 구분을 지킬 것.
