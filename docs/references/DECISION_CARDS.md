# 결정 카드 — 승인 전에 채우고, 승인 뒤에 남긴다 (2026-09-20 신설)

- 왜: 사용자 쪽 오류는 대부분 **"그 결정이 함께 정하는 것"이 안 보인 채 승인된 것**이었다.
  실제 사례 — 자본 3,000만원 결정이 노출 50% 정수화 실패를 품고 있었다 / topn 정리 승인이 DDM −96.9% 오탐을 품고 있었다 /
  "분기마다" 가 첫 분기에도 적용되는지가 5일 뒤에야 질문으로 나왔다 / 지정가 주문은 Claude 제안인데 결정처럼 기록됐다
- 규칙: **Claude 는 승인을 요청할 때 아래 7칸을 채운다.** 빈칸이 있으면 그건 아직 승인을 요청할 준비가 안 된 것이다
- 이 문서는 결정의 **색인**이다. 상세는 PLANS 번호로 간다

## 카드 양식 (7칸)

```
1 무엇을 정하나      한 문장. 정하지 않는 것도 한 줄
2 선택지            (가)/(나)… 각각의 결과. "안 함" 도 선택지다
3 함께 정해지는 것   이 결정이 자동으로 확정하는 것들 (여기가 가장 자주 빠진다)
4 닿는 기존 결정     이 결정이 바꾸거나 전제하는 이전 결정 번호
5 오늘 달라지는 것   실측 숫자로. "영향 없음" 이면 왜 없는지
6 되돌릴 수 있나     되돌리는 방법과 비용. 못 되돌리면 그렇게 적는다
7 확인 시점         언제 무엇을 보면 이 결정이 맞았는지 아는가
```
