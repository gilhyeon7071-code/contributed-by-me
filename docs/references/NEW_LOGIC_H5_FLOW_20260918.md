# 가설 H5 — 외국인·기관 순매수

- 상태: **DRAFT** (2026-09-18 1차 측정). 코드 `src/measure_flow_signal.py`
- 자료: `_cache/investor_flow/*.parquet` (2026-08-28 부터 매일 수집 중, KOSPI 447종목/일)

## 1. 설계 (새 규칙대로 검정력부터)

```
신호  장 마감 뒤 나오는 그날의 (외국인 + 기관) 순매수 금액 ÷ 시총, 상위 10%
진입  다음 거래일 종가 (신호를 마감 뒤에 아니까 당일엔 못 산다)
청산  진입 + k 거래일 종가
대조  같은 날 전체 KOSPI 표본의 중앙값 수익률 (같은 날이라 시장 방향이 지워진다)
단위  날짜
```

## 2. 결과

| 보유 | 독립 날짜 | 스프레드 평균 | 양(+) 날 | p | **최소 탐지 효과** |
|---|---|---|---|---|---|
| 1일 | 42 | +0.11% (중앙 +0.21%) | 62% | 0.164 | **0.40%p** |
| 5일 | 7~8 (겹침 제거 후) | −0.20 ~ +0.63% | 3~5/8 | 0.45~1.00 | 0.90~3.31%p |
| 20일 | 1~2 | — | — | — | 계산 불가 |

## 3. 겹침 함정 — 잡아낸 것

겹침을 그대로 두고 세면 20일 보유가 **+2.35%, 양 70%, p=0.093** 으로 나왔어요.
그런데 매일 신호를 쓰면 20일 창이 19일씩 겹쳐요. 날짜가 독립이 아니라 **p 가 가짜로 작아져요.**
겹치지 않게 잘라내면 관측이 1~2개라 아무 말도 못 해요.

**규칙에 추가**: 보유 k일 짜리는 **k일 간격으로 잘라낸 표본**으로 판정한다.

## 4. 지금 말할 수 있는 것

- **1일 보유는 판정할 만한 힘이 있어요**(최소 탐지 0.40%p). 그런데 관측된 효과가 +0.11~0.21% 로
  **왕복 비용 0.35% 보다 작아요.** 매일 사고팔면 비용이 매번 드니 이 크기로는 남는 게 없어요
- 5·20일은 자료가 2.6개월뿐이라 **아직 판정 불가**. 1년 모이면 5일은 독립 표본 50개가 돼요
- 방향은 양(+)이고 62% 의 날에 이겼어요 — 버릴 근거도 아직 없어요
