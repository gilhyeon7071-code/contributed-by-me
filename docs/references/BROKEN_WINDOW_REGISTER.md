# 고장 구간 대장 (Broken Window Register)

작성 2026-09-09. 근거 대화: 사용자 지적 —
> "검증만 몇 달을 하고 있기 때문에 검증 시작·중간·현재 모두 완벽하지 않은 로직으로
> (매매가 처음부터 끝까지 돌지 않은) 상태로 검증을 한 것이고, 매일같이 오류 수정·문제점
> 도출을 하고 있기 때문에 기존에 적어놓은 기록들이 모두 맞다는 가정하에 진행하는 것은
> 또 다른 오류를 부르지 않을까"

## 이 문서가 하는 일

PLANS 는 **시간순 작업 기록**이라 "그때 무엇이 고장나 있었는가" 를 담지 않아요.
그래서 과거 결론을 인용할 때, 그 결론이 **어떤 고장 위에서 측정됐는지** 알 수가 없어요.

이 표는 그걸 답해요. **결론을 인용하기 전에 이 표와 대조해요.**

**전부 다시 측정하자는 문서가 아니에요.** 무엇을 믿을 수 있고 무엇을 다시 봐야 하는지를
가르는 데 씁니다.

### [수리 2026-09-10] 사용자 판단으로 고쳤다

> "규정이니 현재의 규정 또는 규칙이 명확하고 고칠 명분이 충분하다면 수정을 하는게 맞아"

def _relax_rs_lim(value, frac, floor=-0.10):   # generate_candidates_v41_1
