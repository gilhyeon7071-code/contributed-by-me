## 09-14(월)에 볼 것 — 순서대로

### 1. 일봉 종가·거래량의 정의가 바뀌는가  ← **가장 중요**

```
확인       krx_daily 의 09-14 종가가 15:30 단일가인가, 20:00 최종가인가
방법       15:30 직후 한 번, 20:30 이후 한 번 수집해 같은 종목의 close/volume 비교
왜 중요    value = 종가 x 거래량 으로 유동성 게이트를 건다.
           거래량 정의가 바뀌면 **그날부터 임계값의 의미가 달라진다**
           (value_floor_20e 등 전 게이트가 영향)
```

### 2. 동결 라운드가 성립하는가

```
대상   RD_20260831_flow_h10 (16:30 수집 배치, 판정 2027-08)
확인   수집 원자료의 정의가 09-14 부터 바뀌는가
결과   바뀌면 라운드는 **09-14 이전/이후로 갈린다.** 원장에 적어야 한다
```

### 3. 보유분 무감시 구간이 실제 위험이 되는가

```
현재   16:00~20:00 에 손절·트레일이 돌지 않는다 (_in_krx_session 밖)
       그리고 계좌의 topn 포지션은 애초에 손절이 없다 (EXIT_OWNERSHIP_RULES 배경)

          위험 청산 집행 경로를 앞당길 근거가 된다

       15:30 시점 대비 계좌 평가액 변화를 본다
```

## [2026-09-12 개정] 저녁 배치 시간표를 옮겼다 — 관측 전에 옮긴 이유

애초 계획은 *"09-14 전에는 무엇이 들어오는지 모르니 관측만 한다"* 였다.
그런데 시간표를 실측해 보니 **관측을 기다릴 수 없는 것이 있었다.**

```
16:00~20:00 애프터마켓이 열리면 "마감 후 작업" 8개가 **장중**에 돈다
```
이 중 **그날 시장 자료를 새로 수집하는** 작업은 기다리면 안 된다.
장중에 찍은 값이 원장에 들어가는 순간 **그날 데이터의 정의가 바뀌기 때문**이다.
관측하려고 일부러 틀린 값을 기록할 수는 없다.
