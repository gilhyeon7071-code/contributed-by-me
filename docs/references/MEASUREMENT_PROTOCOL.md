# 측정 절차

**무엇을 재기 전에 여는 문서.** 아홉 줄이고, 각 줄에 **왜 있는지**가 붙어 있다.
이유 없는 규칙은 다음에 건너뛰게 된다.

작성 2026-09-13 밤. 계기는 **같은 밤에 계산 결함을 여섯 번 낸 것**이다.
같은 사람이 같은 밤에 했는데도 매번 방법이 달랐다 — 어떤 스크립트는 겹침을 보정했고
어떤 것은 안 했고, 상폐를 넣은 것도 있고 아닌 것도 있었다.

**이 문서만으로는 안 된다.** 2026-09-13 낮에 `before-you-touch` 스킬을 만들고
10분 뒤에 어겼다. 내가 불러야 뜨는 것은 안 걸린다. 그래서 아래 [기계] 표시가 붙은 줄은
측정 스크립트가 스스로 확인하게 만든다. 나머지는 이 문서에 의존한다.

## 측정 전

### 1. 형성 시점의 종목수를 찍는다  [기계]

```
왜   오늘 밤 여섯 결함 중 **두 개**가 이것이었다.
     파생 지표가 결측이면 그 종목이 조용히 유니버스에서 빠진다.
     그러면 "필터를 넣었더니 수익이 좋아졌다" 로 보인다. 필터 효과가 아니라 표본 변화다.

실측  ATR14 를 창 자른 뒤 계산  -> 첫 13거래일 결측 -> 2020년 1월이 통째로 빠짐 -> +1.2%p 왜곡
     v_accel 이 거래대금 손상일에 결측 -> 2026년 1~3월이 빠짐 -> 10.09% 가 14.58% 로 부풀음

규칙  파생 지표는 **창을 자르기 전에** 계산한다.
     형성일별 종목수를 출력하고, 직전 대비 급감하면 멈춘다.
```

### 2. 기준선을 먼저 정한다 — **실제 대안 + 구성일치 둘 다**

```
왜   기준선이 없으면 좋은지 나쁜지를 말할 수 없고,
     기준선이 틀리면 반대로 말하게 된다.

실측  "KOSPI200 대비 -10%p 완패"  ->  구성일치(코스피43/코스닥57)로 재니
     **-3.70%p, t=-1.10 (유의하지 않음)**

규칙  두 개를 같이 낸다. 용도가 다르다.
       선택 능력을 재려면    -> 스타일 일치 기준선
       할지 말지를 정하려면  -> 실제 살 수 있는 대안 (ETF 등)
     그리고 **같은 날짜·같은 정제**로 잰다. 창이 다르면 비교가 아니다.
```

### 3. 가설과 합격선을 먼저 적는다

```
왜   결과를 보고 나서 기준을 정하면 항상 통과한다.
     이 저장소는 "게이트 통과 = 합격" 으로 써왔는데
     그 게이트에는 **수익성 조건이 아예 없었다**.

규칙  재기 전에 적는다 — 무엇을 기대하고, 얼마면 채택하고, 얼마면 버리는가.
     예상과 실측이 다르면 **그 차이 자체가 발견**이다.
```

## 측정

### 4. 겹치는 구간은 **비중첩 블록**으로 t 를 낸다

```
왜   h10 수익은 10일씩 겹친다. 매일을 독립 표본으로 세면 t 가 부풀려진다.

실측  고ATR 십분위   겹침 미보정 t=-4.10  ->  비중첩 블록 t=-3.33

규칙  h 간격으로 블록을 뽑아 그 블록들로 t 를 낸다.
     **과거에 적힌 t 값은 전부 이 보정이 안 돼 있다.** 인용하지 말 것.
```

### 5. 상장폐지는 **-100%** 로 반영한다

```
왜   상폐 종목을 넣어도 마지막 거래일까지만 보면 절반만 고친 것이다.
     그 뒤 0 이 되는 부분이 빠진다.

실측  바스켓에 담겼던 종목 중 97개가 상폐. 넣으면 **8.43% -> 1.02%**

참고  한국 정리매매는 7거래일·단일가·가격제한 없음.
     KCMI 실측으로 전년 대비 약 1/8 (-87.5%).
     -100% 는 최악 가정이지만 보수적인 쪽이라 이것을 쓴다.
```

### 6. 선택은 **전일 정보만**  [기계]

```
왜   한 줄 차이로 결과가 뒤집힌다.

실측  전일 거래대금 기준   0.53%
     당일 거래대금 기준 136.01%     **+135%p**

규칙  선택에 쓰는 모든 값은 shift(1) 이상.
     확인법: 피처 전체를 하루 더 밀어도 결과가 유지되는가.
     (2026-09-13 실측: -1.195 -> -1.130. 추가 누출 없음)
```

### 7. 생존편향 — 2020년 이후만 쓴다

```
왜   2015~2019 백필 패널에 상장폐지가 **한 건도 없다**.
     2,269종목 5년간 0건. 나중 시점 종목 목록으로 과거를 채운 것이다.

주의  창을 **제거해서** 편향 크기를 재면 안 된다. 편향과 레짐이 섞인다.
     제대로 재려면 같은 창에서 상폐 종목을 넣고 비교한다.
     (2026-09-13 에 이 실수를 했고, 1.35%p 는 철회했다)
```

### 8. 시행 원장에 한 줄 추가한다

```
왜   시행 횟수를 모르면 다중검정 보정이 **원리적으로 불가능**하다.

실측  DSR n_trials 가 4 였다 (참값 375+).

     그리고 자동 튜닝 로그를 30일 정리가 지워서 **참값을 영원히 모른다.**

규칙  사람이 돌린 탐색 + 자동 발동, 둘 다 센다.
     날짜 붙은 파일에 두지 않는다. append-only 원장에.
     기계가 적고 사람이 맥락을 덧붙인다.
```

### 9. 통과 기준 |t| > 3.23,  그리고 **마이닝 헤어컷 26%**

```
왜   |t| > 1.96 은 **한 번만 검정할 때**의 기준이다. 우리는 수백 번 했다.
     문헌 관행은 3.0 (Harvey-Liu-Zhu, 팩터 316개 집계).
     기계 탐색 공간이면 3.8~4.0 을 권하는 연구도 있다.

     그리고 통과해도 실거래에서는 줄어든다.
     McLean-Pontiff: 표본 외 **-26%** (순수 마이닝 몫), 공표 후 -58%.
     인상적인 백테스트일수록 마이닝 비중이 크다.

규칙  |t| > 3.23 을 넘고,  효과에 **0.74 를 곱한 뒤** 판단한다.
     예: 합격선 +1.17%p 면 실제로 찾아야 하는 것은 +1.58%p
```

### 10. 한 방법으로 판정하지 않는다

```
왜   방법을 조금만 바꿔도 답이 크게 달라진다.
     2026-09-13 밤 실측: 필터 하나를 잘못 넣었더니 기준값이 10.09 -> 14.58 (+45%).
     그게 실수라서 고쳤지만, 실수가 아니어도 같은 일이 일어난다.
     한 조합만 보고 판정하면 그것이 18/20 인지 3/20 인지 알 수 없다.

규칙  같은 질문에 여러 경로로 답한다. 바꿀 축은 보통 이 다섯이다.
       신호 정의    ATR14 / 표준편차20 / 고저폭 / 잔차변동성
       구간 나누기  십분위 / 오분위 / 삼분위 / 연속값 회귀
       보유기간    h5 / h10 / h20 / h40
       가중        동일가중 / 거래대금가중
       기간 쪼개기  연도별 / 레짐별 / 전후반
     결과는 숫자 하나가 아니라 **답의 분포**다. 몇 개가 같은 방향인지를 보고한다.

함정  **조합을 많이 돌리는 것 자체가 다중검정이다.**
     20가지로 재서 좋은 것을 고르면 그건 분산이 아니라 탐색이고,
     9번의 다중검정 문제가 그대로 돌아온다.

     그래서 순서가 규칙이다:
       **조합 목록을 먼저 적는다 -> 전부 돌린다 -> 전부 보고한다**
     좋은 것만 고르지 않는다. 이것이 '분산' 과 '탐색' 의 차이다.

주의  **단조로우면 좋은 것이 아니라 의심해야 한다.**
     진짜 효과는 보통 어딘가에서 꺾인다. 끝까지 단조로우면
     통제 안 된 다른 축을 타고 있는 것일 수 있다.
     실측: 주가 하한을 0원 -> 20,000원 으로 올릴수록 단조롭게 좋아졌다.
           최적점이 없다는 뜻이고, 실제로는 규모(대형주) 효과를 보고 있었을 수 있다.
```

### 11. 초과수익으로 판정하지 않는다 — **포트폴리오로 만들어 본다**

```
왜   횡단면 초과수익(알파)이 양수인 것과
     그 종목들로 만든 포트폴리오가 돈을 버는 것은 **다르다**.
     부호가 뒤집힐 수 있다.

실측  v_accel 상위  패널 초과수익 +0.78%p, 27/27 견고, t=5.61
                  포트폴리오로 사면 **-21% ~ -42%**

이유  1) 초과수익은 '당일 유니버스 평균 대비' 다. 절대 수익이 양수라는 뜻이 아니다.
        변동성이 큰 종목은 복리로 굴리면 깎인다
     2) 상위 5~10% 만 뽑으면 종목이 18~35개가 되어 분산이 무너진다

규칙  신호를 채택하기 전에 **반드시** 포트폴리오로 만들어 본다.
     보유기간·재구성주기·종목수·비용·회전을 넣고, 판(신호 없음)과 비교한다.
     판보다 못하면 그 신호는 없는 것이다.
```

### 12. 하한·조건은 **형성일에만** 적용한다  [기계]

```
왜   보유 중에 조건을 벗어난 종목을 그날 빼면, 실제로는 들고 있는데
     계산에서만 사라진다. 회전이 폭발하고 비용이 과대계상된다.

실측  주가·거래대금 하한을 매일 적용   회전 179% -> **993%**
                                비용후 9.38% -> 5.86%  (-3.5%p)

규칙  선별 조건은 형성 시점에만 건다. 한 번 사면 다음 형성일까지 들고 있는 것이다.
     확인법: 회전율을 출력하고 재구성 주기와 맞는지 본다.
            월 1회 재구성인데 회전이 연 900% 면 어딘가 틀렸다.
```

### 13. 채택 전에 **무작위 대조**를 돌린다  [기계]

```
왜   탐색을 많이 하면 무작위에서도 좋은 것이 나온다.
     그리고 탐색 횟수를 안 세면 보정을 계산할 수조차 없다.

실측  2026-09-13 저녁, 100회 이상 조합을 돌려 고른 신호
       단일 검정      p = 0.005   (무작위 200개 중 1개만 이김)
       무작위 최대 대비  **졌다**   (0.695 vs 0.702)
     -> 탐색량을 감안하면 우연과 구별되지 않는다

규칙  같은 절차로 **무작위 신호 200개 이상**을 만들어 돌린다.
     무작위는 지속성이 있어야 한다(종목별 고정 점수 + 잡음).
     매일 새로 뽑으면 회전만 폭발해 불공정한 대조가 된다.

     채택 기준: **무작위 최대를 넘어야 한다.** 평균이나 중앙값이 아니다.
               탐색을 N회 했으면 무작위도 N회 뽑은 것과 같은 자리에 있다.

예외  시점 규칙(언제 줄이나 같은 것)은 **반대로 걸어 보는 것**이 더 강한 검정이다.
     실측: MA200 아래 50% (0.767) vs MA200 위 50% (0.562).
     무작위에서는 이런 비대칭이 나오지 않는다.
```

### 14. **역할이 다르면 잣대가 다르다**  [2026-09-13 밤 추가]

신호는 역할이 여섯이다. 후보탐색 / 진입 / 보유 / 청산 / 위험차단 / 실행.
**한 잣대로 여섯을 다 재면 안 된다.**

```
후보탐색·진입   수익/변동, 초과수익        평균을 올리는 것이 목적이다
위험차단       한도 도달 확률, 왼쪽 꼬리   평균을 **깎으면서** 꼬리를 자르는 것이 목적이다
              -> 수익/변동으로 재면 구조적으로 진다. 보험료를 내니까
청산          보유기간별 실현손익 분포
실행          체결가 대비 슬리피지, 비용   수익률 축이 아니라 비용 축이다
```

**실측 증거** (46절). 같은 필터를 두 잣대로 쟀다.

```
급등 상위10% 제외   낙폭 p=0.000 (무작위 500회 중 0회)
                  수익/변동 p=0.452 (무작위와 구별 안 됨)
고베타 상위20% 제외  낙폭 p=0.000        수익/변동 p=0.550
```

09-13 낮에 19개를 전부 수익/변동으로 재서 뺐다. 그 판정은 **그 잣대 안에서는 맞았고**,
틀린 것은 잣대 선택이었다.

### 14-1. 차단 잣대는 **우리 중단 조건**에서 가져온다

고점 대비 낙폭(MDD)은 우리 중단 조건이 아니다.
정의 5항목의 실제 한도는 **원금 대비 -25%** 다.

```
MDD 로 재면    고베타 제외가 -35.61 -> -25.94 로 크게 이긴다
한도로 재면    기준선 3.8% vs 고베타 0.0%,  그런데 중단 포함 수익이 186% -> 92%
              **네 한도(-15/-20/-25/-30) 전부에서 기준선이 이긴다**
```

지표를 바꾸면 결론이 뒤집힌다. **운영 규칙에 있는 것으로 재라.**

### 14-2. 유리 신호와 차단 신호를 **분리해서 기록한다**

같은 축(예: 변동성)이 유리 신호도 되고 차단 신호도 된다.
결론 등록부에 넣을 때 **어느 역할로 어느 잣대에서 판정했는지**를 같이 적는다.
안 적으면 다음 사람이 "ATR 탈락"만 보고 차단 역할까지 닫힌 것으로 읽는다.

**홀드아웃이 없다.** 2026-09-10 에 소진했다.

그래서 지금 하는 모든 측정은 **같은 데이터에서 고르고 같은 데이터에서 채점**한다.
2026-09-13 밤의 ATR 필터가 그 예다 — 전·후반으로 나눠보니

```

                   그동안 탐색하면 그 자료도 오염된다
규칙               앞으로 쌓이는 구간을 **봉인**하고, 정한 뒤에 **한 번만** 연다.
                   열고 고치고 또 열면 그건 홀드아웃이 아니라 훈련 자료다
```
