## 4. 우리 실제 노출 — 균등이 아니다

배제 필터의 실효 이득 = (제외 셀의 알파) x (**그 셀에 실린 비중**)

```
체결 원장 (2020년 이후 매수 375건)      후보 CSV (19일치 195행)
  평균 ATR 분위  6.67 (균등 4.5)        평균 7.15
  9분위 비중     16.8% (균등 10%)        26.7%
  0~4분위 합계   14.3%                   7.2%
```

**우리 로직은 고변동성 종목을 골라 산다.** 하위 5개 분위는 사실상 안 산다.

```
균등이었다면   1.195% x (0.1/0.9)     = 0.13%p
우리 실제      1.195% x (0.267/0.733) = 0.43%p
```

**단서**: 후보 CSV 는 19일치 195행뿐이고 체결 기준이면 0.24%p 다. 둘 다 표본이 얇다.

**단조롭게 나빠진다.** 저ATR 자체에는 매수 알파가 없다는 뜻이다
(저ATR 1분위 초과수익 +0.030%, t=0.27).
ATR 상위 10% 제외이 만든 +3%p 는 **저변동성을 사서**가 아니라
**고변동성 꼬리만 잘라서** 번 것이다. 그 이상 기울이면 손해다.
문헌(Blitz)과 일치 — 고변동성은 잘라내면 되고, 저변동성 알파는 별개 구성에서만 나온다.

### 9-2. v_accel 회피 — 안 든다


### 9-4. 주가 하한은 **임의 선택**이다


실제로는 주가가 규모 대리변수라 **'대형주가 좋았다'를 보고 있는 것**일 수 있다.
5,000원은 3,000만원 배분을 고려한 실무적 타협일 뿐이다.

### 9-5. 표본 외 분할 — 진짜 표본 외 검정이 **아니다**

```
                전반(2020~23.6)   후반(23.7~26.9)
기준                  6.71           13.97
ATR 상위10% 제외        8.23           18.73
필터 효과              +1.52          +4.75

```

효과가 후반에 **더 크다.** 과적합이면 후반에 사라져야 하므로 그 점은 좋다.
그런데 **전반 t=0.29 는 사실상 0이다. 전반 3.25년만 봤으면 이 필터를 못 찾았다.**
즉 저는 전체를 보고 ATR 을 골랐으므로 이것은 표본 외 검정이 아니다.
제대로 하려면 전반만 보고 정했어야 하는데, 전반에서는 유의하지 않아 **애초에 안 골랐을 것**이다.

## 24. 표본 외 분할 — ATR 때와 같은 문제

```
                  전반(2020~23.6)   후반(23.7~26.9)
판 (조건 없음)            4.99          18.81
```

2023년 하반기 이후 시장에서만 작동하는 것일 수 있다.

## 26. ★ 이것은 신호가 아니라 **방어 장치**다

### 레짐을 쪼개니 방향이 갈렸다

```
상승월 (46개월)   일평균 초과  -0.0126%
하락월 (35개월)   일평균 초과  +0.0337%
```
**하락장에서 벌고 상승장에서 잃는다.**

```
연도    판      필터     효과     KOSPI200
2020  28.28   19.30   -8.97    +32.52   <- 강세장, 크게 짐
2021   7.64   11.22   +3.58     +1.26
2022 -16.83  -11.82   +5.01    -26.15   <- 폭락장, 이김
2023   9.33   14.86   +5.54    +22.98
2024  -6.59   -6.28   +0.31    -11.22
2025  46.40   54.48   +8.08    +90.67
2026  34.28   37.47   +3.19    +79.91

필터가 이긴 해 6/7
일평균 초과 +0.0077%   비중첩 20일 블록 83   **t = -0.25**
```

**CAGR 로는 +4.6%p 인데 통계적으로는 0이다.**
상승월(-0.0126)과 하락월(+0.0337)이 상쇄해 평균이 0에 가깝고 산포만 크다.
CAGR 이 높은 것은 **하락장에서 덜 잃어 복리 경로가 보존된 것**이지
평균 수익이 높아서가 아니다.

### 그 해석이 위험지표에서 확인됐다

```
              CAGR   연변동   최대낙폭   하방변동   수익/변동   -20%일수
판           13.38   24.36   -41.55    20.54     0.55      554
+ 필터        15.93   22.93   -39.21    18.98     0.69      **121**
KOSPI200     22.26   29.92   -40.94    23.58     0.74      674
```

**-20% 아래에 있던 날이 554 -> 121일. 4.6배 줄었다.**

```
연도별 최대낙폭    판      필터     개선
2020           -41.5   -39.2    +2.3
2022           -33.8   -28.4    +5.4
2023           -31.0   -24.0    +6.9
2024           -29.7   -19.3   +10.4
2025           -30.0   -20.8    +9.2
2026           -27.9   -22.2    +5.7
```
매년 개선된다.

### 위험조정으로 보면 지수에 근접한다

```
수익/변동   판 0.55  ->  필터 0.69  ->  KOSPI200 0.74
```
CAGR 로는 -6.3%p 격차인데 위험조정으로는 0.05 차이다.
그리고 **변동성이 KOSPI200 보다 7%p 낮다** (22.93 vs 29.92).

### 다만 손실 한도는 못 막는다

```
판     2020-03-11 에 원금 -15% 도달
필터   2020-03-09 에 도달   <- 이틀 더 빠르다
```
**코로나급 폭락은 방어가 안 된다.** 정의 5의 원금 -15% 한도는
시작 시점에 따라 첫해에 걸린다. 이건 정의를 다시 볼 사유다.

### 결론

```
평균 초과수익    0 (t=-0.25)          -> '신호를 찾았다' 고 말하면 안 된다
낙폭 방어       실재 (-20%일수 4.6배)   -> 방어 장치다
위험조정        0.55 -> 0.69           -> 지수(0.74)에 근접
손실 한도       코로나급은 못 막는다
```

정의 2가 **절대수익**이라 이 방어는 값이 있다.
낙폭이 줄면 손실 한도에 덜 걸리고 3년 기간 조건도 버티기 쉬워진다.
다만 **평균 수익을 올리는 것은 아니다.**

### 사전등록 조합 검정 (MA 기간 5 x 유지비율 4 = 20)

```
MA기간별 평균    60 0.764   100 0.884   150 0.782   200 0.748   250 0.717
```

**MA100 이 혼자 튄다.** 이웃(60=0.764, 150=0.782)이 안 따라온다.
이웃이 안 따라오는 봉우리는 과적합 신호라, 최적값이 아니라 **평범한 MA200** 을 골랐다.

### 시점이 맞는지 — 이게 핵심 검증

```
(1) 100% 보유              15.93   22.93   -39.21   0.695
(2) 항상 50% 만             8.39   11.47   -21.74   0.732
(3) MA200 아래면 50%       14.60   19.03   -27.73   **0.767**
(4) MA200 **위**면 50%      9.65   17.18   -34.16   0.562

(3)-(4) = +0.205   같은 양을 줄여도 **언제** 줄이느냐가 이만큼
(3)-(2) = +0.035   다만 개선의 절반은 '노출 축소' 자체 효과다
```

**반대로 하면 0.767 -> 0.562 로 기준보다도 나빠진다.** 시점이 무작위가 아니다.

### MA 아래는 손실 구간이 아니라 저수익 구간

```
MA200 아래   612일 (37%)   연환산 +10.6%

```
그래서 **전량 현금(유지 0%)이 50% 보다 나빴다** — 벌 수 있는 것을 포기하니까.

분기 재구성 로직에 걸 자리가 없고, 검증된 적도 없다.

## 30. ★★ 무작위 대조 — 오늘 저녁 결론을 한 단계 내린다

절차 9번(다중검정)을 적어놓고 **오늘 저녁 탐색은 세지 않았다.**
그래서 같은 방식으로 **무작위 신호 200개**를 돌려 비교했다.
(종목별 고정 무작위 점수 + 잡음 -> 상위 절반 선택. 지속성이 있어야 공정한 대조가 된다)

```
판 (조건만)           CAGR 12.89  변동 24.40  수익/변동 0.528
거래대금 안정 상위절반   CAGR 15.93  변동 22.93  수익/변동 0.695

무작위 200개
  CAGR      평균 12.69  중앙 12.72  **최대 17.60**
  수익/변동   평균 0.516  중앙 0.519  **최대 0.702**
```

### 두 줄이 정반대를 말한다

```
단일 검정으로 보면
  진짜를 이긴 무작위 비율   CAGR 1.0%  /  수익변동 0.5%
  -> p = 0.005 ~ 0.010.  매우 유의하다

탐색량을 감안하면
  무작위 최대 CAGR 17.60  >  진짜 15.93
  무작위 최대 SR  0.702  >  진짜 0.695
  -> **우리가 찾은 것은 무작위 200개 중 최고보다도 못하다**
```

오늘 저녁에 **100회 이상** 조합을 돌리고 그중 제일 좋은 것을 골랐다.
무작위로 100번 뽑아도 이 정도는 나온다.

### 그래서 22절의 판정을 내린다


## 46. 차단 신호 재채점 — **잣대가 틀렸다는 지적을 받고 다시 쟀다**

### 지적

사용자가 신호 15분류와 **역할 6단계**(후보탐색 → 진입 → 보유 → 청산 → 위험차단 → 실행)를
제시하고, **매수 유리 신호와 매수 차단 신호를 분리하라**고 했다.

그 틀에 오늘을 얹으면 이렇다.

```
15분류 중  채택 1 (시장·국면 = MA200)   검정후 탈락 6   판정불가 2   **손도 안 댐 6**
손도 안 댄 것: 평균회귀 · 호가체결 · 이벤트 · 청산 · 실행 · 리스크

6역할 중  **후보탐색 하나만** 검정했다
```

그리고 더 중요한 것 — **19개를 전부 하나의 잣대로 쟀다.** "수익/변동이 오르는가".
그건 유리 신호의 잣대다. 차단 신호는 평균을 올리려고 넣는 게 아니라 꼬리를 자르려고 넣는다.
평균으로 재면 구조적으로 진다. 보험료를 내니까.

**어젯밤 마지막 문장 "신호 후보가 전부 탈락했다"는 범위를 잘못 말한 것이다.**
정확히는 "후보탐색 역할의 신호가 전부 탈락했다"이다.

### 차단 잣대를 어디서 가져왔나

우리 R10 '사고' 정의는 **집행 경로**다 (안 나간 것을 나갔다고 믿는 것).
가격 백테스트에 갖다 쓰면 또 자를 잘못 쓰는 것이다. 그래서 안 썼다.

1차로 낙폭·하위5%·최악20일·Sortino 로 쟀고, **무작위 제외 대조**를 같이 걸었다.
종목을 빼면 그냥도 낙폭이 바뀌기 때문이다.

### 1차 — 차단 잣대로 재니 두 개가 살아났다 (`n3_block.py`)

## 47. [2026-09-14] 비중 하한 — **3,000만원으로 200종목은 불가능하다**

### 정수 주수로 담으면 성과가 **올라간다** — 이걸 이득으로 읽으면 안 된다


제약을 걸었는데 성적이 좋아졌다. **제약이 좋아서가 아니다.**
꼬리를 버리고 정규화하면 대형주 쏠림이 커지고, 2020~2026 구간에서 대형주가 좋았다.
**어제 확인한 '시총가중 > 동일가중'(+0.195)과 같은 사실의 재등장이다.**
새 정보가 아니라 같은 베팅을 더 세게 한 것이다. 그래서 이 +0.061 은 근거로 안 쓴다.

자금이 커질수록 기준선에 수렴하는 것(0.959 -> 0.919 -> 0.908)이 그 증거다.

### 종목수를 줄이면 (3,000만원, 정수 주수)

```
상위 200종목   26.66  27.81  -39.17  0.959   못담은비중 20.05%
상위 100종목   25.78  27.62  -38.40  0.933            13.65%
상위  50종목   25.86  28.11  -39.93  0.920             7.77%
상위  30종목   25.13  28.18  -39.82  0.892             3.88%
상위  20종목   26.37  28.46  -39.85  0.927             1.94%
```

**20~200 사이에 단조성이 없다.** 30종목(0.892)이 20종목(0.927)보다 나쁘다.
차이가 노이즈다. **성과로는 N 을 고를 수 없다.**

### 최소 비중 절사는 답이 아니다

```
최소비중 0.1%   0.961   못담은비중 21.31%
최소비중 0.5%   0.916            33.22%
```

절사할수록 못 담는 비중이 오히려 는다. 버리는 것을 명시적으로 늘리는 것이라 당연하다.

### 판정과 권고

```
확정된 사실   3,000만원에서 200종목은 물리적으로 불가능하다
못 고른 것    어느 N 이 나은지. 20~200 차이는 노이즈다
```

성과로 못 고르니 **집행 제약으로 정한다.**

```
3,000만원 / 200종목 = 15만원  -> 주가 5만원이면 3주. 정수 오차 17%
3,000만원 / 100종목 = 30만원  -> 6주.  오차 8%
3,000만원 /  50종목 = 60만원  -> 12주. 오차 4%     <- 권고
3,000만원 /  30종목 = 100만원 -> 20주. 오차 2.5%   분산이 얇아진다
```

**권고: 3,000만원 구간에서는 상위 50종목.** 근거는 성과가 아니라
정수 주수 오차 4% 와 못담은 비중 7.8% 다. 둘 다 한 자릿수로 들어온다.
자금이 1억을 넘으면 100종목, 3억을 넘으면 200종목으로 되돌린다.

**이것은 정의 변경이다.** '시총 상위 200' 은 자금에 따라 달라지는 수이지
검증으로 고른 수가 아니었다. 그 사실을 정의에 적어야 한다.

### 미리 적은 예상과 대조

```
예상 1  절반 이상이 1주도 못 살 것          ->  맞음 (평균 99/200)
예상 2  그 비중 합은 5~15% 로 작을 것       ->  **틀림.** 20%, 최악 35%
예상 3  종목수를 줄여도 성과 비슷할 것       ->  맞음 (20~200 이 노이즈 안)
```

예상 2가 틀린 것이 중요하다. 20%는 무시할 수 있는 크기가 아니다.
**소수 주식을 허용한 백테스트와 실제 계좌가 포트폴리오의 5분의 1만큼 다르다.**
