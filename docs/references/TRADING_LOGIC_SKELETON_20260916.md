## 1. 구조 — 목표 포트폴리오를 가운데 둔다

어떤 전략이든 판단 시점마다 **목표 포트폴리오 하나**를 낸다고 봐요.
단기 매매는 목표가 자주 바뀌는 경우이고, 분기 리밸런싱은 드물게 바뀌는 경우예요.
진입·청산 신호는 "목표에 이 종목을 넣는다 / 뺀다" 로 표현돼요.

```
[판단 층]
  D1 입력 데이터      판단에 쓰는 데이터와 그 기준 시각
  D2 모집단          무엇 중에서 고르는가 (거래 가능·상장 상태·유동성)
  D3 시장 국면        risk_on / neutral / risk_off
  D4 후보 탐색        관찰할 종목 목록 — 매수 승인 아님
  D5 후보 분류        매수 가능 / 관찰 / 제외
  D6 선정·순위        목표에 넣을 종목과 순서 (점수·가중 방식·종목 수·집중 제한)
  D7 목표 포트폴리오   종목별 목표 비중·금액·수량 (상한·현금·비용·정수 주식·노출 한도 반영)
        │
        │  계약: 목표 포트폴리오 하나 (시각·기준일·ID)
        ▼
[집행 층]
  E1 주문 생성        주문 = 목표 − 현재 보유
  E2 주문 상태기계     의도 → 준비 → 제출 → 부분·전량 체결 → 취소 → 재시도 → 종료
  E3 체결            가상 또는 브로커. 주문 ID 로만 귀속
  E4 원장            현금·수량·비용·평가·NAV·낙폭
        │
        ▼
[평가 층]
  V1 사후 평가        신호·역할별 기대값, 표본 수, 기간별 재현성
  V2 적용 판단        필터로 추가 / 일부 대체 / 별도 유지 / 폐기

[위험 — 층을 가로지름]
  판단 층에서는  노출 한도 (D7 에 숫자로 드러나게)
  집행 층에서는  ALLOW / BLOCK / HARD_STOP 판정값 + 사유 + 해제 조건
```

보유 관리(추가·축소)와 청산은 **목표 포트폴리오를 바꾸는 판단**이라 D4~D7 안에서 다뤄요.
정기 리밸런싱은 D7 을 새로 내는 시점의 규칙이에요.

## 2. 섞지 않는 것 네 가지

| 섞지 않는 것 | 이유 |
|---|---|
| 탐색·진입 신호 ↔ 차단 신호 | 차단은 독립 안전장치예요. 후보가 부족하다고 차단을 같이 완화하면 안전장치가 아니게 돼요 |
| 위험 판단 ↔ 수량 곱셈 | 노출 한도는 정당한 도구예요. 문제는 위험 계산 결과가 주문마다 **보이지 않는 배수**로 들어가는 거예요. 한도는 D7 에 숫자로, 차단은 판정값으로 |
| 판단 층 ↔ 집행 층 | 둘 사이 계약은 목표 포트폴리오 하나. 집행이 체결 가능성 때문에 조용히 목표를 바꾸면 판단이 틀렸는지 집행이 틀렸는지 못 가려요 |
| 사후 평가 ↔ 자동 변경 | V1 은 권고까지. 결과가 파라미터를 자동으로 바꾸면 무엇을 검증했는지 사라져요 |

## 3. 칸마다 적는 것

칸을 구현하거나 판정할 때 이 여섯 줄을 채워요. **채우는 순서가 수정의 전제는 아니에요.**

```
입력      데이터·기준 시각·결측 시 동작
판정      산식·임계값·분기  (임계값 근거: 실측 / 제도 사실 / 집행 제약 / 전략 전제 — 없으면 "미정")
출력      위 구조의 판정값·산출값
경계      이 칸이 하지 않는 것
안전장치   결측·날짜 불일치·오류 시 어떤 값으로 떨어지는가 (미검증은 PASS/FAIL 이 아닌 세 번째 값)
산출물     어느 파일·키에 남는가
```

## 5. 성과 검증에서 지킬 것

- **칸별로 잰다.** 최종 수익률만으로는 어느 칸이 틀렸는지 모른다
- **두 검증을 가른다.** 제외·차단 검증(막았어야 할 걸 막았나, 막지 말아야 할 걸 막았나) / 기회 탐색 검증(비용 차감 후 기대값이 있나)
- **안 산 것도 기록한다.** 관찰·제외·차단된 종목의 이후 가격이 없으면 차단의 대가를 못 잰다
- **기준선은 실제 대안 + 구성일치 둘 다**, 같은 날짜·같은 정제
- **표본 수를 먼저 계산한다.** 합격선을 가를 수 없는 표본이면 기다려도 답이 안 나온다
- 순서: 과거 → 기간 외 → 비용 포함 → 가상매매 → 실시간 연결
- 마지막에 전체 E2E: 목표 포트폴리오 → 주문 → 체결 → 원장 → 통계 (AGENTS.md 10절)

(측정의 구체 함정은 `MEASUREMENT_PROTOCOL.md` 에 있어요. 여기에 옮기지 않아요)
