# 청산 소유권 및 충돌 규칙

작성 2026-09-11 (PLANS 348~351). 상태: **규칙 확정, 집행 미무장.**

이 계좌에는 청산 규칙이 다른 엔진이 둘 이상 붙는다. 규칙이 없으면 둘이 같은 포지션을
동시에 팔거나(초과매도), 한쪽 규칙이 영원히 발동하지 않는다(측정 오염). 아래가 그 규칙이다.

---

## 배경 실측 (2026-09-11)

```
계좌 보유 6종목 / 평가 1억 / 전부 topn_stage1 소유
topn_stage1        청산 규칙 = 보유 13거래일 만기 매도. 손절/트레일/TP 없음
paper_engine_v41_1 청산 규칙 = 손절 -5% / TP [10,20,40]% / 트레일 act 12% pct -10% / 보유 8일 만기
```

두 규칙을 같은 포지션에 붙이면 이렇게 된다(당일 실측):
```
012210  보유3일 +25.92%  ->  TP10% 30% + TP20% 40% = 즉시 70% (1,136주) 매도, 트레일 무장
나머지 5종목             ->  발동 없음
그리고 보유만기 8일 vs 13일  ->  topn 만기 규칙은 **영원히 발동하지 않는다**
```

---

## R1. 일상 청산 소유자는 포지션당 정확히 하나

일상 청산 = 손절 / 트레일 / 익절 / 보유만기.
소유자가 아닌 엔진은 그 포지션에 일상 규칙을 적용하지 않는다.

**근거**: 두 규칙이 동시에 붙으면 항상 더 이른 쪽이 이긴다. 늦은 쪽 규칙은 코드에
존재하지만 한 번도 발동하지 않으므로, 그 하네스의 측정(A3/A4/A5, 보유기간별 성과)이
실제로는 다른 규칙의 결과가 된다. 위 실측에서 topn 의 13일 규칙이 정확히 그 상태가 된다.

**따름정리**: topn 포지션을 `paper_state.open_positions` 에 넣는 방식은 **채택하지 않는다.**
`paper_engine/entry.py:6357` 에서 `open_pos` 는 손절·트레일·TP·만기·DDM 의 **단일 공통 입력**이다.
DDM 만 골라 연결할 수 없다. 넣는 순간 R1 을 위반한다.

## R2. 위험 청산은 소유권을 넘어선다 — 그리고 넘어서는 것은 위험 청산뿐이다

위험 청산 = DDM Stage 청산 / 킬스위치 강제청산 / 수동 비상청산.

**근거**: 탈출구는 계좌에 하나여야 한다. 소유 엔진이 손절을 안 가진 실험 하네스여도,
계좌 전체가 무너지면 팔려야 한다. 소유권은 "누가 일상 규칙을 적용하나" 이지
"누가 이 돈을 잃어도 되나" 가 아니다.

## R3. 위험 청산은 선택과 집행을 분리한다

```
선택   계좌 전체 보유(브로커 잔고)에서 고른다.  open_pos 가 아니다
집행   소유자의 발주 경로를 쓰지 않는다. 전용 경로 하나로 낸다
```

**근거**: 소유자 경로로 내면 그 엔진의 원장·수량·빈자리 계산이 깨진다.
2026-09-09 003230 사고가 같은 계열이다 — 부분매도로 원장에서 행이 사라지자
빈자리가 1에서 2로 늘고 주문 파일이 다시 만들어졌다.

## R4. 미체결 매도 수량은 예약된 것으로 본다

매도 주문이 걸린 수량은 체결 전까지 어떤 엔진도 다시 팔지 않고, 빈자리로도 세지 않는다.
`tools/topn_build_orders.py:202` 가 이미 이 규칙을 구현하고 있다(매수 측 빈자리).
위험 청산도 같은 규칙을 따른다.

## R5. 소유자는 선언되어야 한다

선언이 없는 브로커 보유는 `UNATTRIBUTED`, 둘이 주장하면 `AMBIGUOUS` 로 경보한다.
구현: `tools/broker_ledger_reconcile.py` (2026-09-11).
**"손절 없음"은 경보 대상이 아니다** — 이상이 아니라 현재 설계다. 매일 우는 경보는 무시된다.

## R6. 소유자 이전은 명시적 행위다

자동 흡수를 금지한다. `tools/topn_reconcile.py` 의
*"브로커에만 있는 종목은 흡수하지 않아요"* 가 이미 이 규칙이다.

## 이 규칙에 따른 (나) 의 구현 형태

```
1. (가) 지표 연결     DDM 이 브로커 기준 자산으로 낙폭을 잰다
                      생산자 완료(broker_account_basis_latest.json), 소비 연결 대기
2. 위험 청산 선택기    Stage 도달 시 **계좌 전체**에서 약한 순으로 고른다 (R3 선택)
                      먼저 관측 전용으로 낸다 - 무엇이 대상이 될지만 기록
3. 집행 무장          전용 경로로 실제 매도. **사용자 승인 사항**
```

topn 의 일상 청산 규칙(13일 만기)은 그대로 둔다. 위험 청산이 그 위를 지나갈 뿐이다.
