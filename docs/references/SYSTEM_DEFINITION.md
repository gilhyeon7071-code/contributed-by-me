## 왜 이 문서가 생겼나

2026-09-13 까지 이 저장소에는 정의가 없었다. 우선순위(①매매가능 ②수익률 ③오류수정)는
있었지만 그건 순서지 정의가 아니다. **수익률이 무엇 대비인지 정해진 적이 없어서**
합격선이 두 개로 갈려 있었고 — 신호 알파 1%p / 지수 초과 6%p — 한 번도 맞춰지지 않았다.
통과해도 이기지 못하는 시험을 몇 달 보고 있었다.

그리고 구현이 정의를 앞섰다. 각 구성요소가 전제를 담고 있는데 그 전제를 잰 적이 없다.

```
"거래대금이 큰 종목이 낫다"   -> value_min 하한으로 구현   실측: 방향이 반대
"코스닥도 넣어야 기회가 많다"  -> 유니버스에 포함          실측: -4.73% (2020~2026)
"자주 갈아타야 수익이 난다"    -> 일 단위 회전            실측: 회전이 25%p 를 먹는다
```

셋 다 구현이 먼저였고 검증은 없었다. 그리고 구현되고 나면 **존재 자체가 유지의 이유**가 됐다.

이 문서는 그 순서를 뒤집는다. **정의 -> 요구사항 -> 계획 -> 구현.**
기존 코드는 계획이 요구할 때만 불려 나온다. 안 불리면 판단 대상도 아니다.

## 정의 여덟 항목

### 1. 무엇을 위한 것인가
**돈을 버는 것.**

배우는 것·시장을 이해하는 것은 목적이 아니라 수단이다.
거기 도움이 안 되는 조사는 하지 않는다.

### 2. 무엇과 비교해 성공인가
**절대수익.** 지수 대비가 아니다.

따라서 "지수보다 낮다"는 그 자체로 실패가 아니다.
다만 지수와의 비교는 **참고로 계속 기록한다** (R3). 안 적으면 나중에 후회한다.

### 3. 얼마를 걸 것인가
**모의 진행 후 소액 실계좌. 실계좌 3,000만원.**

3,000만원인 이유: 바스켓이 약 198종목이라 종목당 15만원. 대부분 1주 이상 살 수 있다.
더 적으면 종목 수를 줄여야 하고, 종목이 줄면 결과가 운에 좌우돼 판정이 오래 걸린다
(실측: N=6 에서는 알파를 못 쟀고 N=50 이면 쟀다).

### 4. 얼마나 손댈 것인가
**월 1회 점검. 안전평가 후 자동화.**

월 1회는 **사람이 보는 주기**다. 시스템은 계속 돈다.
-> 그래서 한 달이 한눈에 보이는 자리가 필요하고(R8'),
   월 1회만 봐도 사고를 놓치지 않을 장치가 필요하다(R14).


**CAGR 9%p 를 가중 방식만으로 버리고 있었다.**

### 검정을 통과한 근거

```
비중 상한 조합    무상한 0.822 / 20pct **0.874** / 15pct 0.863 / 10pct 0.832 / 5pct 0.756
                -> 20pct 정점의 **매끄러운 봉우리**. 튀는 값이 아니다

무작위 대조      진짜 0.874  vs  무작위 가중 200개 최대 0.714
                -> **크게 넘는다.** 오늘 통과한 것 중 격차가 가장 크다

방어 반대 시험    아래면 50pct 0.874  /  위면 50pct 0.656
                -> 시점이 맞다

종목 수         78/100/200 이 모두 0.817~0.822 로 무관 -> 분산 큰 200 채택
```

### 이것이 무엇인지 정확히

```
이것은     지수를 재현하고 두 가지를 얹은 것
얹은 것    비중 상한 20pct  (+0.052)
          MA200 방어      (+0.070)
신호       여전히 **0개**
```

**'지수를 이기는 전략' 이 아니라 '지수를 조금 다듬은 것'** 이다.

## 판정 가능성 — 0에서 다시 시작

시행 횟수를 셀 수 없으면 무엇을 재도 다중검정 보정이 틀린다.
실제로 DSR `n_trials` 가 **4** 였다(참값 375+). 고치니 0.5928 -> 0.0055 로 뒤집혔다.

```
세는 범위    사람이 돌린 탐색  +  자동 발동  둘 다
과거         0 에서 다시 시작 — 과거 탐색은 근거 자격을 잃는다
장치         기계가 자동 기록 + 사람이 맥락 추가
```

**경계** — 무엇이 0으로 돌아가고 무엇이 남는가:

```
사실 기술 — 유지
  코스닥 -4.73% / 코스피 8.44% / 지수 19.40~22.50%
  거래대금 문턱이 높을수록 나쁘다 (단조)
  회전이 비용을 먹는다
  우리 신호에 매수 알파 증거가 없다 (탐색이 아니라 전수 확인)

가설 탐색 — 참고로 내림. 근거로 못 씀
  atr 회피 +1.68%p
  저변동성 vol_20 재현
  그 외 채택 후보로 올랐던 것 전부
```

```

상폐 반영    2020년 이후는 정상 (마지막날 평균 -5.76%)
```

## [2026-09-14] 정의 변경 — **'상위 200' 은 자금에 따라 달라지는 수였다**

47절 실측. ① 매매가능 축의 마지막 미측정 항목이었다.

### 무엇이 틀렸나

`시총 상위 200` 은 검증으로 고른 수가 아니었다. 백테스트가 **소수 주식을 허용**해서
아무 수나 넣을 수 있었을 뿐이다. 실제 계좌는 정수 주수다.

```
3,000만원, 시총가중 상한 20%, 분기 형성일 27개
  1주도 못 사는 종목  평균 99 / 200   (최악 150)
  그 목표 비중의 합   평균 20.05%     (최악 35.18%)
```

**정의는 200종목인데 실제로 담기는 것은 약 101종목이다.**
백테스트와 실제 계좌가 포트폴리오의 5분의 1만큼 다르다.

### 새 규칙

```
종목수 N 은 자금에 따라 정한다. 기준은 **종목당 배분액**이다.

  3,000만원   ->  상위  50종목   종목당 60만원   정수오차 4%   못담은비중 7.8%
  1억원       ->  상위 100종목   종목당 100만원  정수오차 ~3%
  3억원       ->  상위 200종목   종목당 150만원  정수오차 ~1%
```

### 이 수를 **성과로 고르지 않은** 이유

```
3,000만원 정수주수 기준 수익/변동
  200종목 0.959 / 100종목 0.933 / 50종목 0.920 / 30종목 0.892 / 20종목 0.927
```

단조성이 없다(30 < 20). 차이가 노이즈다. **성과로는 N 을 고를 수 없다.**
그래서 집행 제약(정수 주수 오차, 못담은 비중)으로 정했다.

### 정수 제약이 성적을 올린 것을 이득으로 읽지 않는다

```
기준(소수주식 허용)   0.898
정수주수 3,000만원    0.959      <- 제약을 걸었는데 좋아졌다
정수주수 1억원        0.919
정수주수 3억원        0.908      <- 자금이 커질수록 기준선에 수렴
```

꼬리를 버리고 정규화하면 대형주 쏠림이 커진다. 09-13 에 확인한
**'시총가중 > 동일가중'(+0.195)과 같은 사실의 재등장**이다. 새 정보가 아니다.
자금이 커질수록 사라지는 것이 그 증거다. 이 +0.061 은 근거로 쓰지 않는다.

### 붙는 단서

```
최소 비중 절사는 답이 아니다. 절사할수록 못 담는 비중이 늘어난다
  (0.1% 절사 -> 21.31%,  0.5% 절사 -> 33.22%)
50종목은 3,000만원 구간에서만 유효하다. 자금이 바뀌면 다시 정한다
이 측정에는 무작위 대조를 걸지 않았다. N 선택을 성과 근거로 쓰지 않으므로 불필요하다
```
