## 3. 칸별 여섯 줄 (초안 — 판정 칸은 "미정")

### D4 후보 탐색
```
입력      D2 모집단 + (미정: 어떤 정보)
판정      미정 — 가설 출처(R-J5) 먼저
출력      관찰 목록 (매수 승인 아님)
경계      매수 결정·수량을 하지 않는다
안전장치   입력 결측·기준시각 불일치 → 빈 목록이 아니라 "판정 불가" 로 떨어지고 B1 바구니로 대체
산출물     날짜 없는 append-only 후보 기록 (안 산 것 포함)
```

### D5 후보 분류
```
입력      D4 관찰 목록
판정      매수 가능 / 관찰 / 제외 — 제외 사유는 제도·유동성·집행 제약으로만(실측 근거 없는 필터 금지)
출력      분류와 사유 코드
경계      순위·비중을 정하지 않는다
안전장치   미검증 필터는 PASS/FAIL 이 아닌 세 번째 값
산출물     분류 기록 + 제외 종목 이후 가격(차단의 대가 측정용)
```

### D6 선정·순위
```
입력      D5 매수 가능 목록, (기본값) 시총
판정      미정 — 기본은 B1 의 시총 순서. 바꾸려면 R-J1·R-J2 충족 근거
출력      목표에 넣을 종목·순서·종목 수
경계      비중 상한·정수화·노출은 D7
안전장치   근거 미충족 → 시총 순서(B1)로 떨어진다
산출물     선정 기록 + B1 대비 차이 종목
```

## 4. 아직 정하지 않은 것 (이 초안의 빈칸)

- **판단 근거(D4·D6 판정)** — 무엇으로 시장과 다른 결과를 내는가. **여기서 옛 결론(무엇이 되고 안 되더라)을 전제로 쓰지 않아요.** 후보는 새 자료로 판정해요
- 판단 빈도 — 분기(표본 부족) vs 더 짧게(비용 증가). R-J1 과 R-J2 가 서로 당겨요
- 판단 층 로직과 B1 을 같은 모의계좌에서 나눠 돌릴지(전략 자본 분리) 여부
