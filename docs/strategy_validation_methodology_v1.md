# 전략 검증 방법론 V1

## 목적

기존 운영 로직의 점수·Gate를 정답으로 가정하지 않는다. 다운로드 가격 이력으로 전략 문법을 검증하고, 통과한 문법만 후보·실행·가상매매·자본배분 단계로 순서대로 올린다.

## 고정 원칙

1. 가격 무결성 계약을 통과한 실제 전역 거래일만 사용한다.
2. 전략 문법, 진입 시점, 청산 시점, 비용, 기준선은 한 검증 실행 안에서 동일해야 한다.
3. 국면·상황·신호는 처음부터 모두 교집합으로 묶지 않는다. 전략 단독, 국면 단독, 신호 단독, 2축, 3축 순서로 추가 효과를 확인한다.
4. OOS 결과로 전략 문법이나 임계값을 재조정하지 않는다. 새 가설은 별도 버전으로 다시 시작한다.
5. 기존 `final_score`, 운영 Gate, 주문 기록은 연구 전략의 후보 자격 기준으로 사용하지 않는다.
6. 운영 Gate·LOCK·주문 경로는 연구 결과가 승인되기 전까지 그대로 유지한다.

## 단계와 승격 기준

| 단계 | 검증 대상 | 통과 기준 | 다음 단계 |
|---|---|---|---|
| 0 | 가격 이력 | 가격무결성 계약, 실제 h1/h2/h5, 중복 없음 | 1 |
| 1 | 전략 문법 | 문법 일치, 미래정보 없음, 시간순 학습·OOS 결과 저장 | 2 후보 |
| 2 | 후보 선별 | 전략 문법을 바꾸지 않은 선별 규칙이 OOS에서 추가 가치를 보임 | 3 |
| 3 | 실행 계약 | 동일 진입·청산·비용 후 OOS 결과가 전략 단계와 모순되지 않음 | 4 |
| 4 | 기본 가상매매 | 승인 후보 입력으로 cash·position·T+2·BUY/SELL 원장이 재현됨 | 5 |
| 5 | 자본배분 | 4단계 승인 원장에 한해 수량·비중·최대보유·MDD를 비교 | 연구 승격 검토 |

## 판정 상태

- `RESEARCH`: 문법 또는 가설이 정의됨.
- `CANDIDATE`: 1단계 결과가 저장됐으나 실행 검증 전.
- `REPRODUCIBLE`: 1~3단계가 같은 계약으로 시간순 재현됨.
- `PAPER_READY`: 4단계 가상매매 원장이 생성되고 정합성이 확인됨.
- `NOT_SUPPORTED`: 해당 단계에서 OOS 또는 계약 검증에 실패함.

`REPRODUCIBLE` 이전의 결과는 수량·자본배분·운영정책 변경 근거로 사용하지 않는다.

## 현재 고정된 연구 계약

- 공통 진입: 신호일 종가.
- 공통 청산: 실제 전역 거래일 h1/h2/h5 종가.
- 비용: 수수료 0.5%, 슬리피지 0.1%.
- 기준선: 동일 날짜·동일 조건 시장 기준선 및 비용 후 절대수익률을 함께 기록.
- 초기 전략 문법: 볼린저 평균회귀, 252일 돌파, 거래량 돌파.

## 현재 결정 상태

- 0단계: 통과.
- 1~3단계: 통합 계약으로 재검증 중. 승인 전략 없음.
- 4~5단계: 선행 단계 미통과로 보류. 기존 수량 원장은 참고 실험이며 승격 근거가 아님.
- 운영 적용: 없음.
