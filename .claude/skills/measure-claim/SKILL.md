# 측정 전에 연다

**이 저장소에는 이미 규약이 있다. 문제는 그게 측정하는 순간에 안 열린다는 것이다.**
새로 쓰지 말고 아래를 읽는다.

## 1. 해당 규약 문서를 먼저 읽는다

```
docs/references/NEW_SIGNAL_VALIDATION_STANDARD.md   연구 목적 **모든 측정 라운드**
                                                    (재측정·재현·기준선 교체·축 탐색 포함)
                                                    ** AGENTS.md 가 참조하지 않는다. 그래도 읽는다 **
docs/references/STRATEGY_VALIDATION_GUARD.md        전략·후보생성·국면·신호·실행 가설 (AGENTS.md 269행)
docs/references/METRIC_CITATION_PROTOCOL.md         지표를 **인용**할 때 (AGENTS.md 280행)
docs/references/CONCLUSION_REGISTER.md              과거 결론의 유효/철회 상태
docs/references/BROKEN_WINDOW_REGISTER.md           그 기간에 매매가 돌고 있었나
```

## 2. 데이터 함정 — 여기서 결론이 뒤집힌다

```
가격 패널 zero-padding   krx_daily 가 주말을 close=0 으로 채운다 (20% 행)
                         필터 안 하면 결과가 **역전**된다 (2026-07-27 실측)
기업행위               가격제한 ±30.5% 로 정제. 안 하면 분할이 급등으로 잡힌다
value int32 오버플로    value = 종가 x 거래량. 24거래일 손상 이력
유니버스 결손           생산이 Raw/ 를 안 읽어 27개월 62.8% 결손이었던 적이 있다
통합 로더               archive + Raw, 코스닥 포함. 빠뜨리면 결론이 뒤집힌다
```

## 3. 통계 함정

```
다중검정          탐색 횟수를 원장에 적고 보정한다. n_trials=4 로 박혀 있어
                  0.5928 PASS 가 보정 후 0.0055 FAIL 이 된 적 있다
겹침 미보정 t값    인용 금지
일 클러스터링      거래 단위 유의성은 p 를 과대평가한다. 날짜 단위로 묶는다
내생적 청산        실현 구간으로 선정을 재면 부호가 뒤집힌다. 고정 구간으로 잰다
look-ahead        재무 IC 가 78% look-ahead 로 무효였던 적 있다
검정력            표본이 그 효과를 잡을 수 있나. 없으면 "기각"이 아니라 "판정 불가"
```

## 4. 기준선은 **실제 대안 + 스타일 일치** 둘 다

```
실제 대안     그 돈으로 실제 할 수 있던 것과 비교한다
스타일 일치   코스닥 54% 포트를 KOSPI 와 대면 "완패" 가 나오지만
              구성일치로 재면 t=-0.92 로 유의하지 않다 (2026-08-28, 하루에 둘 다 어겼다)
데이터 자신    기준선을 데이터에서 뽑으면 항상 통과한다. 달력·외부 기준을 쓴다
```

## 5. 비용

왕복 **0.358%** (trades_calc.csv 권위, 사용자 승인).
신호가 t=4~5 로 확실해도 비용이 먹는 경우가 대부분이었다. 비용 0 결과를 결론으로 쓰지 않는다.

## 6. 절차

```
가설과 합격선을 **먼저** 적는다 (사후 조정 금지)
탐색 라운드마다 원장에 한 줄 추가한다
반증 경로가 있나 — 없으면 그건 검증이 아니라 설계다
결과는 CONCLUSION_REGISTER 에 상태를 붙여 등록한다
```
